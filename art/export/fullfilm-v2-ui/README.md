# 真实截图槽与 UV 检测

`uv-test-16x9-1920x1080.png` 只用于检查方向、宽高比和边缘裁切，不是软件界面，也不计为制作过程实截。模型默认材质为中性无字色，不烘焙假 Unity/Blender 标题栏。

主屏 `UI_Main_16x9` 对应 1.28×0.72 m、完整 UV 0—1；接受 1920×1080 或 2048×1152 的实际 Blender/Unity/素材编辑截图。其他槽由主代理裁切同一真实截图后赋材质：`UI_LeftHierarchy` 0.44×0.70 m，`UI_RightAssets` 0.46×0.70 m，`UI_Timeline` 1.20×0.14 m。三个 `UI_Thumbnail_00/01/02` 均为0.256×0.144 m的独立16:9平面，有独立实体背板。

任何需要保留完整软件标题栏的画面都放主屏；侧栏可裁切但不要拉伸完整界面。由主代理通过 Unity Pipeline 创建/替换贴图材质。
