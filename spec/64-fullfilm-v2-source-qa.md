# 全片 V2 整合素材来源核验

日期：2026-10-17。审计逐项比对图集清单、归档素材表、公开媒体表、本地原图与展示导出；完整路径、SHA-256、像素尺寸、16×8 网格坐标和焦点引用见[整合素材审计 JSON](../data/fullfilm-v2-integration-source-audit.json)。

图集共有128条来源记录，128个原图哈希互不重复。128个原图及128个展示导出均存在；原图当前 SHA-256 与清单记录一致，原图尺寸也一致。每项导出 SHA-256 均不同于原图，这是构建器将来源图按1600×1200边界缩放、编码为展示 PNG 的预期结果。总图为4096×2048像素，16列×8行，每格256×256像素。

V2新增素材共69项：`fullfilm-v2-archive-materials.json` 的52项和 `fullfilm-v2-public-media.json` 的17项全部按 ID、原图路径映射到图集；无缺项、无交叉重复。`source_page_count=93` 按构建器的来源页键规则复算一致：每项依次取 `source_page_url`、`source_url`、`image_url`，最后回退到原图路径。清单中原始 `source_url` 字段有97个不同值；它与93的差异是统计字段不同，不能据此判为映射错误。

焦点清单的14条主图索引均与事件 `file` ID 相符。每个事件的主图和次图均在审计 JSON 中分别关联到来源记录，并保留各自的日期元数据；不可用主图日期替代次图日期。

字幕组配对需要把内容日期与捕获日期分开标示：声同招募帖正文时间为2008-12-23 13:02，截图于2026-10-17从当前论坛页面捕获，当前论坛皮肤并非2008年的界面。次图是 Aegisub 3.2 工具文档截图，截图日期未标。该配对可以说明翻译工作流程，不能称两张都是2008年截图，也不能据此认定当时已使用此版本界面。

BT 配对也有两种日期：CBN 周刊封面对应期号日期为2009-12-21，相关报道发布日期为2009-12-17；BTChina 搜索框图刊于2009-12-07报道，原始截图捕获日期未标。VRChat 配对分别对应2022-07-25的官方 EAC 公告配图和2010-11-03的3Q选项材料。三组素材应在运行时各自显示日期及日期类型。

来源记录中的 `source_date` 有时是 Wayback 捕获时间，有时是报道日期、事件日期、Commons 元数据时间或软件/文档记录时间。运行时日期标签应使用明确的日期类型，例如“Wayback 捕获”“报道发布”“帖文时间”“截图 DateTimeOriginal”或“来源记录日期”；捕获日期和被描绘事件日期并列时应分别呈现。

归档页的视觉复核结果：24张页面布局可辨；另有2张布局可辨但模糊了普通用户账号；7张遮盖了个人正文或具体作品详情；8张仅为局部或残缺页面；11张主要呈现入口或文本目录。太平洋电脑网论坛素材只捕获到侧边框架和入口标签，不含完整论坛正文，应标为局部入口，不得称为完整历史界面。以上分组及来源 ID 在审计 JSON 中逐项列出。
