# 29 前三段历史图像来源

日期：2026-10-16。此索引供前三段第二版场景选材，机器可读逐图记录在 [data/episode123-historical-images.json](../data/episode123-historical-images.json)。当前收录 33 张本地参考图，来源、图像性质、日期依据、尺寸、路径与校验哈希均按图记录。

## 选材与年代标注

优先保留可以一眼辨认的真实旧界面、同期网页与官方原图。图像拍摄日、网页/公告发布日期、软件版本时期和档案条目日期分别登记；页面发布日期不自动当作截图日期。后世在虚拟机运行旧系统所得截图、文档内的工具界面图、同期报道图片和官方信息图都明确标注性质，不冒充同期摄影。

所有列入清单的本地文件都已逐张或按缩略图联系页目视检查；已排除广告、无法回放的 BTChina 错误页、重复的 EAC 截图、低清/不相关截屏。没有使用生成图。

## 来源范围

### Windows 与旧软件

Windows 95、98 和 XP 的桌面/Explorer 图来自 Internet Archive 保存的原系统/虚拟机条目。它们能还原原版 OS 界面，但截图是后世真实系统运行画面，未标日期的图像不写成 1990s 或 2001 年同期拍摄。XP 两张来自预发布 Build 2474，需保留“beta”性质。

IE5 的 Textfiles.com 图片保留真实浏览器框架和旧网页内容，来自 Internet Archive 的 IE5 条目配图；条目产品年份是 1999，图像拍摄日未标。IE6 图片的 Commons 说明明确为 IE 6.0 SP2 / Windows XP SP3，Commons 原始上传时间是 2014-10-21，不等同拍摄日。Winamp 皮肤截图是 Internet Archive 保留的可视化皮肤预览图；其日期属于皮肤条目。eMule 0.47c 图由 Wikimedia Commons 记录原始上传于 2006-10-23，是目前这组里具有明确同期上传时间的软件界面图。

### 字幕与传播工具

Aegisub 图是 3.2 文档中的 Translation Assistant 界面。原文和译文分区清楚，可用于字幕劳动场面；文档没有标截图日期，也不能证明每个字幕组都使用该工作流。eMule 图展示真实 P2P 客户端；它不证明某个 BT 站或单一传输流程。

### 中文互联网页面

校内网、天涯和早期新浪微博页面由本地 Chromium 对 Internet Archive Wayback Machine 的固定时间戳回放页截屏。校内网捕获于 2007-12-01 05:26:45 UTC，天涯 BBS 捕获于 2009-08-05 07:54:32 UTC，新浪微博首页回放显示 2009-11-01。校内网部分远端图片没有存档，首页文字和版式仍可见；截图只表现各自存档页面，不外推整个平台或所有用户经历。

本次试取 BTChina 2009 年首页时，Wayback 返回无法回放的错误页，因此没有把错误页冒充成 BTChina 原界面，也未放入资产清单。

### 病毒、3Q 与 EAC

3Q 两图来自 2010-11-03 同期报道：一张为 QQ 用户公开信窗口，一张为选择/卸载相关页面。它们作为报道保存的事件视觉材料，不独立裁决双方争议性指控。Panda 图来自 2007-02-04 新浪关于网民二创的报道，画面是卡通梗图，不是病毒样本或感染电脑截图；相关场景只能作为病毒事件带来的网络表达来使用。

VRChat EAC 两图来自 2022-07-25 官方安全公告：标题配图和 Secure Instances 说明图。第二张是官方信息图/网页示意，不应当作玩家客户端的原始弹窗截图。

### VRChat Hub 与制作流程

10 张 New Hub 图来自 VRChat 官方 2017-11-18 Steam 公告。直接 CDN 文件与 Steam News API 正文内的附件地址逐张做 SHA-256 对照；图像具体拍摄时间未知，按公告配图记录。它们分别覆盖入口、人群、Travel Map、Help Area、Avatar Hall/镜子、Event Hall、New Worlds、Panosphere 与互动雕塑。

Unity/VRChat SDK/旧网站页图来自 2017 年玩家世界制作教程及其后续图像。教程发布日期、图像文件名时间、截图拍摄时间不是同一概念：图像文件名中的日期只作为来源线索；Unity 2017.4.15f1 对话框一图来自 2018-12-18 文件名的后续补图。2018 Avatar World 列表中的场景图只代表一条社区推荐清单，不能代表全体玩家的 Avatar 偏好。

## 可用的历史留存来源与访问核查

- [Internet Archive Wayback Machine](https://web.archive.org/)：目前最适合做可读旧网页回放；使用固定时间戳 URL，并以 Wayback 横幅/时间线确认实际捕获日期。请求时间会重定向到邻近捕获，重定向后的日期才是页面图像的实际日期。外链图片、CSS、脚本可能缺档，页面截图不等于完整站点备份。
- [Internet Archive Items](https://archive.org/)：适合查找旧软件、旧媒体及条目所附图像；条目的出版日期可能描述软件版本或收藏品，不能直接当作单张截图拍摄日期。
- [Archive-It](https://www.archive-it.org/)：机构/项目运营的主题收藏，可补充公共网页存档；是否覆盖某站点与时期需逐项查目录。
- [Common Crawl Index](https://index.commoncrawl.org/)：可查抓取记录并恢复部分 HTML/资源，适合作为 Wayback 没有结果时的补充；它不保证能直接还原交互或视觉布局。
- [Wikimedia Commons](https://commons.wikimedia.org/)：不是完整网页时光机，但单张图的源文件、作者、许可、上传时间和说明较清楚；本清单的 eMule/IE6 图片可在 Commons 详情页核验。

实际访问状态以本轮 2026-10-16 检查为准：Wayback 上校内网、天涯和新浪微博的指定旧页面可回放；BTChina 候选快照在本轮返回错误页并被排除。Internet Archive 的 Windows/IE/Winamp 参考条目可访问，Wikimedia 的 eMule 与 IE6 文件详情可访问；Aegisub 文档、3Q 报道、Sina 2007 报道和 VRChat 官方公告可访问。原新浪微博评测图片旧图床目前返回不含图像的 PHP 响应，所以没有把失效直链列为可用文件。
