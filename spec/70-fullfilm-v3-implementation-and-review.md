## 可重复入口

源码在 `unity/Assets/OldWebMap/Scripts/OWV3{Presentation,BasePresentation,Signal,AudioFloor,Details}.cs` 与六个新Shader。构建脚本均位于 `unity/AgentScripts/`，由 `tools/run_fullfilm.py` 调用，经锁定本工程的Unity Pipeline运行。

- `OWV3EffectsBuild.Core`：音频、面板、彩带、圆柱、波形、光晕、光标、弹幕；随后运行 `UserArt` 更新漫画指针位置。
- `OWV3EffectsBuild.Models / UserArt / Provenance / Timing`：静态资源与时长绑定。
- `OWV3PenBuild.Import / Integrate / AdjustStand`：保真导入、首次实例化、现有实例位置与状态接口。`Integrate`发现已接入时拒绝替换。
- `OWV3Build.Programs / Save`：Udon编译、代理序列化同步与保存。`Create`仅初次复制场景，后续不重复运行。
- `OWV3Validation.Static / Revision / Interactions / Live`：分别检验采样、V3细节、实际射线按钮/时间锚点恢复、完整实际播放。
- `OWV3PenValidation.Draw`：实际ClientSim手部输入拿笔、用笔、原版Udon画线和清除，再验证重播丢笔/隐藏动态墨迹；不替换原版画笔代码。
- `OWV3Review.Capture / Heights`：确定性相机采样；截图期间临时关闭Udon编辑器图标并恢复，不把编辑器图标误当世界内容。
- `OWV3SoftwareCapture`、`tools/prepare_fullfilm_v3_software.py`：Windows软件实际窗口取像、PID核验与裁切；不重绘编辑器界面。

## 验证边界

最终报告与预览统一在 `~/tmp/vrc-old-web-map/fullfilm-v3/` 和 Windows `C:/Users/Chiro/tmp/vrc-old-web-map/fullfilm-v3/`。视频仅为四轨立体声节奏参考，不冒充Unity空间音场录音。测试期间Windows默认输出静音，工程音轨与数字监听信号保持正常。

实际头显的双眼深度、波形发光观感、低身高拿笔、真实远端多人迟到加入和同步笔迹，以及人耳的空间响度仍须用户实机验收。桌面ClientSim、Shader编译和静态距离曲线验证不替代这些项目。

实际单人Udon连续253.44秒已通过：24场、6组界面、4个失效状态、11个软件状态，八源稳定快照最大差0采样；远去段最终监听器AC RMS为0.0360—0.0728。208个静态时间点、21个接收时间锚点、开始/不可暂停/结束/重播和QvPen生命周期通过。实际玩家名牌对照1个ClientSim玩家的API displayName，4个演出人物保持xxxx，报告不保存真实名字。ClientSim重力落地检查覆盖桥、环面与座面。

本地SDK世界包、参考片和最终保存重开状态以 `data/fullfilm-v3-delivery.json` 与同轮reports为准；历史V2交付报告不作V3通过依据。
