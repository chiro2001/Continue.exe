# 47 V5 人物：近场时刻与标志动作

承接 [42](42-episode123-v5-look-and-throughline.md) 第 9 项。V4 的四位演员（小满/阿澄/木木/北辰，`OWV4HubCast` 的 4 个槽位）离观众 5 米以上，几乎不被认出。本模块不改运行时脚本，只重写 `OWV4HubCast` 的关键帧数组：`keyTimes / positions / yaws / gestures / gazePositions`（`index = key*4 + slot`）。创作与数据在 [data/episode123-v5-cast.json](../data/episode123-v5-cast.json)，实现在 `unity/AgentScripts/OWEpisodeV5Cast.cs`，离线自检 `tools/check_episode123_v5_cast.py`。

## 三个近场时刻

坐标为物理米，观众眼柱 (0, 1.35, −2.8)。`OWV4HubCast` 把 `ActorRegionOffset(t)` 加到演员上、`worldFrame` 减去同一旅行量，两者抵消，所以数组里的 x、z 就是演员相对观众的物理位置。三处站位都在关键句带（x ±1.8、z 0.5–1.5）外侧，水平距离 2.25 m，偏轴 32°，离焦点图视线很远。

## 约束与取舍

- 四个槽位共用一张关键帧栅格，每个区间只在前 72% 走完（smoothstep），其余时间停住。长距离只能拆成若干小跳。所有新增走位峰值速度 ≤ 1.18 m/s（验证上限 1.3），4–6 米的路因此需要 8–10 秒，演员要提前出发。
- 新增 3 个关键帧（27.84、94.40、130.00），只落在另三个槽位原地不动的区间，Apply 逐项断言位置、视线与偏航不变。槽 2 在 130.00 之后的 Carry→Present 切换晚约 0.55 秒。
- 绕开关键句带（|x| ≥ 1.92）、2017 入口告示牌与台阶栏杆、营火；演员始终朝向观众眼点（视线 `gaze` 写为眼点）。
- 槽 0 在 104.96–117.76 的闸前等候点由 (−2.4, 5.35) 前移到 (−2.3, 4.2)，仍在第一道闸之前（z < 5.6）。槽 3 离开 2017 世界区后那里只剩槽 2 观察；槽 3 在 106.8 秒回到侧路口，V4 的闸前约束（槽 2 / 槽 3）不变。
- V4 本身没有位置跳变（相邻 0.16 s 采样位移 ≤ 0.77 m），但 Hub 与闸口有多处冲刺（最高 4.8 m/s，槽 1 的 84.48–85.76 等），按“保留 V4 编排”原样继承；新增走位不产生新的快段。V4 里槽 0 与槽 2 在 32.4 秒几乎重叠（约 10 cm），A 的改线顺带消除了它。
- 近场演员在参考眼中处于侧栏 tracker 谱面的下部前方（A 左、B 右），B 的名牌与谱面当前行同高。若要避开，只能把站位再外移，但会靠近 16:9 画框边缘（40.9°），因此未改。

## 构建与验证

顺序：`OWEpisodeV5Cast.Apply()` → `Validate()`。两者都要求编辑器停止、活动场景为 `Assets/Scenes/OWM_Episode123_v5.unity`，不保存场景。

- `Apply()`：由 JSON 内缓存的 V4 表 + 编辑项重建 5 个数组；场景数组与 V4 表或 V5 表一致才写入（可重复运行），否则报错；`ApplyForce()` 才会强制覆盖。写入后同步 Udon 代理并标记场景已修改。
- `Validate()`：经真实 `OWV4Journey.Sample` + `OWV4HubCast.Sample` 每 0.16 s 采样 0–133.12 秒，检查：场景数组等于 JSON 重建结果；演员世界坐标等于表模型；离眼柱 ≥ 0.6 m；三个时刻最近距离 1.8–2.4 m 且在窗口内 ≥ 95% 时间不超过 2.4 m、含规定手势；新增走位速度 ≤ 1.3 m/s、无位移跳变；不进入各区域关键句带；不穿过告示牌、栏杆、营火；新增走位与其他演员 ≥ 0.35 m；手势编号 0–11 且与动画参数一致；闸前停步（V4 规则）；12 个动作 × 5 相位 × 6 个身体的双手不交叉；Idle 脚底包络 < 1 cm、身高偏差 < 1.5 cm；名牌紧跟头部。结果写 `reports/cast-validate.json`，并打印三个时刻的距离表。
- 离线自检不需要 Unity：`python tools/check_episode123_v5_cast.py`，复刻同样的数组重建与采样规则。
