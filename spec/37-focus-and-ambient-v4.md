# V4：可识别焦点、累积历史与原生立体字

本模块沿用全部 V3 成果，新增 `OWV4Montage`、`OWEpisodeV4Montage` 与两支独立 shader，不修改 V3 脚本或资源。它负责中央图像的识别时间、周边快闪和留存、真实图内鼠标、自然弹幕、大字号关键句，以及替代球阵的原生挤出字体。V4 主导演、人物、操作工作台、声源和旅程由其他模块负责。

## 中央焦点的三个阶段

每个 `role=focus` 事件必须有入场、停留和离场，默认入场 0.45 秒、离场 0.55 秒；中间停留 2.4—5 秒。入场从 `from` 飞入 `to`，停留时仅在目标位置附近缓慢移动：横向最多 2.5 厘米、纵向最多 1.8 厘米。离场从 `to` 飞向 `out`；没提供 out 时向同侧移出 5.5 米并后退 1.5 米。图片在整个事件中保持可见，不以逐拍换图代替停留。

`role=periphery` 保留较快的移动和切换。声部起音只给周边图像很小的重心偏移，方向靠近四声部的前方 x≈−1.8、−0.6、0.6、1.8 米；焦点图不被持续脉冲打散。

每槽仅有原图、真实图内指针及可选年代/真实网页标题。没有自绘现代标题栏、来源性质、审核说明、label/result 文案、虚拟按钮或窗底操作说明。完整来源及核验资料保留在事实源和验收页，不进入演出画面。图像自身的原始界面保持完整。

## 留存的历史窗口

每个 region 持久化 48 个历史图片 Quad，共 192 个对象；这些是既有图像的预制副本，不计新素材。前八个分布在前侧，后续窗口逐步延伸到左右侧与身后。半径约 5.6—7.6 米，高度分四层，各窗口朝向区域中心，使用原图自身比例并限制高度。CH01/CH02 的历史窗在左侧、CH03/CH04 在右侧；对应音符使它们向实际前方声源横坐标轻移最多 3.5 厘米，保持声画方位联系。

活动预算随演出从约 8 增至 48。每条历史有明确 `reveal`，只有图像已经进入历史后才可出现。普通阶段只有一个区域的副本参与显示；区域过渡时在旧区和新区分配同一个预算，两区活动历史窗合计仍不超过 48。历史窗口不会每隔几拍换图，原图持续保留直到离开该区域。

实际留存数量受 reveal 约束，可能少于阶段预算。主编排需要给最初八项安排合理的早期 reveal，并为后续时期增加真实历史项；不能用尚未出现的未来界面填满初始墙面。

## 世界共同移动

所有对象挂在 `journey.worldFrame/Revision4Montage`。运行时所有场景 Transform 都写 `localPosition/localRotation`，不读取摄像机位置，也不做跟随摄像机的抵消偏移。

事件 from/to/out 已由主编排包含固定 region 偏移。历史、弹幕、关键句和立体字的区域父对象在构建时调用 `journey.RegionOffset(region)`：0/24/52/80 米。它们随共同 worldFrame 一起移动。预算过渡与主旅程一致：79.36—81.92、86.40—88.32、102.40—104.96 秒。真实玩家、跟头字幕和控制菜单不属于本模块。

## 真实图内鼠标

`cursor_uv` 使用原图左上角为原点的 0—1 坐标。鼠标是窗口的子物体，在图片前 1.8 厘米处，沿 `cursor_from_uv → cursor_uv` 移动，并在 `cursor_at` 短暂按下。没有新增按钮或不属于原图的点击目标。若有真实的后续操作图，可以提供 `result_image` 在点击后切换到该图；没有时不会捏造结果界面。

早期鼠标始终与图片共面且无额外旋转。只有绝对时间超过 `overload_start`，且事件显式设置 `cursor_detach=true`，才可逐步离开平面、向观众方向突出和转动。默认过载起点为 61.44 秒，可由主编排覆盖。

## 自然弹幕与关键句

弹幕来自独立 `comments` 数据，不读取窗口事件的 label/result。若没有提供 comments，构建器使用按时期分组的自然短句作为回退：早期连接回应、论坛语气、字幕/做种感谢、共同观看、失效/补档和少量维护回应。密度先低后升，条件变化后减弱；触发时间从真实音符中挑选，绝不把操作状态直接复制成弹幕。

每区预制 16 个弹幕文本对象，最多 64 个持久对象。只更新当前存活的短句，通常保留 2.4—5 秒；密度由数据事件承担，主编排应避免同一时刻超过槽位承载量。

关键句使用独立 keylines，字号 3.15，黑字白板或白字黑板；面板与文字都有普通世界深度测试，不使用 ZTest Always。它们作为舞台内容随 worldFrame 移动，不替代本地跟头字幕。建议每句不超过约 18 个汉字，以免大字号失去识别优势。

## 真正的圆柱弯排立体字

V2 的 EDGE 原生点字提供了字形参考，V4 不再摆球阵。构建器将 5×7 字形的前面、后面及外轮廓侧壁生成到合并 Mesh，邻接实心格之间不生成内部侧墙，再把顶点弯排到圆柱曲面：

- EDGE：约 0.735 米字高，0.18 米厚度，圆柱半径 2.6 米。
- + FC14：约 0.455 米字高，0.13 米厚度，半径 2.3 米。
- RHINO OF TORMENT：约 0.224 米字高，0.10 米厚度，半径 1.8 米。

每一行一个合并 Mesh，每个区域复用这三份持久网格。字体有真实侧壁、背面、遮挡和眼间视差；没有 TMP 贴片或逐球 GameObject。蓝白格纹、金属高光由新 shader 提供，视线取当前眼的摄像机位置。三行缓慢交错转动，保留正面可读时段。显示区间为片头至 25.6 秒、81.92—92.16 秒与 128—133.12 秒。

## score 合同

主文件为 `AgentScripts/data/episode123-v4-score.json`，保留 V3 的 images、events、slots、scenes。核心事件示例：

```json
{
  "slot": 0,
  "image": "windows98-se-explorer",
  "start": 10.24,
  "end": 14.24,
  "role": "focus",
  "enter": 0.45,
  "hold": 3.0,
  "exit": 0.55,
  "region": 0,
  "from": [-4.2, 2.4, 7.0],
  "to": [0.0, 2.4, 5.8],
  "out": [4.5, 2.7, 7.2],
  "width": 3.0,
  "height": 2.4,
  "channel": 0,
  "year": "1998",
  "web_title": "",
  "cursor_uv": [0.43, 0.27],
  "cursor_from_uv": [0.12, 0.11],
  "cursor_at": 1.2,
  "cursor_detach": false
}
```

事件按 slot/start 排序，同槽不得重叠。from/to/out 为包含固定 region 偏移的局部米坐标；cursor_uv 为图像自身坐标，不加 region。start/end/enter/hold/exit 为秒，`end−start=enter+hold+exit`。真实网页标题只读显式的 event.web_title 或 image.web_title，年代只读 event.year 或 image.display_year，绝不从来源说明自动生成。

顶层可新增：

```json
{
  "overload_start": 61.44,
  "ambient": [
    {"image": "windows98-se-explorer", "reveal": 10.24, "channel": 0}
  ],
  "comments": [
    {"time": 32.0, "text": "字幕组辛苦了", "region": 0, "channel": 3, "duration": 3.6}
  ],
  "keylines": [
    {"start": 45.12, "end": 49.12, "text": "一条字幕，许多双手", "region": 0, "style": "white_on_black"}
  ]
}
```

ambient 最多 48 项；少于 48 时副本循环填充，仍不增加独立素材计数。没有 ambient 时按事件首次出现的不同图像派生。comments 按 time 排序，keylines 按 start 排序。没有给 comments/keylines 时仅提供构建器内的回退，不应把回退当作最终编排已审定。

## 持久化与验证

`OWEpisodeV4Montage.Build()` 仅在已停止的 `OWM_Episode123_v4.unity` 执行，要求先有 OWV4Journey.worldFrame 与真实音乐导演。资源在 Revision4 的 Meshes、Materials、Fonts 中；独立字体从源 TTF 新建 4096 动态单图集，按实际可见文字预填，不复制已有多图集字体，不预填来源档案等隐藏信息。原图使用既有纹理引用，构建不额外生成图像。

两个新 shader 均为真实几何深度测试，并具备立体宏。焦点图/历史图和黑白板写深度，字体 3020 队列位于底板前，保留 LEqual。临时点击按钮、操作说明和球阵均不在 V4 模块中。

公开入口为 `Build()`、`Sample(float)`、`Validate()`；运行器自己 `LateUpdate → director.Elapsed()`。主导演无需逐帧加调用。Build 只 MarkSceneDirty/SaveAssets，不最终保存场景，主代理统一保存。

Validate 核焦点实际停留时间和厘米级漂移、早期鼠标共面/命中原图 UV、每时刻历史活动不超过 48、反向 seek 重复姿态、挤出网格的深度与侧壁法线、关键句真实可见字符数及 shader 错误。报告在用户临时目录 `episode123-v4/montage/`。Builder、运行源码与离线结构检查不能代替真实 Unity/Udon、双眼与镜面、关键帧及实际画面主次验收；这些由主代理统一执行。
