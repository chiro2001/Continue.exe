## 空间总览

整个世界是一张「能走进去的旧网页地图」：脚下是表格线变来的格栅，头顶是深色底与缓慢移动的扫描线，节点悬在格栅之上，节点之间由细线连接，线代表「谁引用过谁、谁分享过谁」。

```
                        ┌──────────── 希望之河（第三幕）
                        │   熄灭的点换色重亮、案例墙沿河展开
    网盘峡 ──► 开源荒原 ──► VRChat 城 ──►
   （限速/失效）   （归档/耗尽）    （被摘除/被导出）
        ▲                ▲                ▲
        └──── 点阵地图主舞台：目录树 + 缩略图 + 名片卡 + 访客计数器 ────┘
                        ▲
                        冷启动（CMOS 自检 / Starting Continue.exe…）
```

- 主舞台是枢纽，四条动线从它分出；演出模式下玩家沿轨道自动前进，自由模式下可以在任何一处停下细看。
- 全片结束时，所有动线收拢回主舞台，地图合拢成一枚磁盘图标，访客计数器归零。

## 地图状态机

节点六态是整片的视觉主轴，也是 Udon 侧唯一需要严格同步的状态。

| 状态 | 画面表现 | 声音 | 玩家靠近时 |
| --- | --- | --- | --- |
| 在线 | 亮点 + 缩略图 + 绿色状态条 | 轻微的电流声 | 弹出名片卡（名称/作者/年份/访问量） |
| 限速 | 进度条卡在 100 KB/s 反复回头 | 断续的滴答 | 弹「开通会员」提示 |
| 失效 | broken image 图标 + 「分享的文件已经被取消」 | 短促的失败音 | 卡片显示最后可用的日期 |
| 归档 | 灰点 + 「最后提交：4 年前」只读 | 低沉的底噪 | 卡片显示最后提交信息 |
| 被导出 | 缩略图被框选、复制粘贴到另一扇窗口 | 克隆/粘贴音 | 卡片显示「已离开这张地图」 |
| 复活 | 同一坐标重亮，但颜色与第一幕不同 | 比在线态更柔和的音色 | 卡片显示复活时间与新形态 |

状态切换只改材质参数、贴图、标签与音效；节点几何体不做增删，避免运行时开销与网络同步量。

## 旧网页美学在 3D 里的落地

| 网页元素 | 三维转译 |
| --- | --- |
| 表格布局 | 地面格栅、节点排布的行列对齐 |
| `<marquee>` | 下缘歌词 HUD 带的滚动与回环 |
| 动画 GIF | 逐帧贴图（2–4 帧循环） |
| 访客计数器 | 空间中的翻页数字牌，片尾归零 |
| `Under Construction` | 施工警戒带围住未完成区域 |
| `Best viewed in 800×600` | 入场处的铭牌 |
| broken image 图标 | 缺失缩略图的占位砖块 |
| 蓝色下划线链接 | 节点间的连线，失效时从中间断成两截 |
| 弹窗 | 第二幕 A 的弹窗墙，可穿过但会遮住视线 |

## 视觉规范

- 基础调色板取自九十年代终端与 CRT：琥珀 `#FFB000`、青 `#00D8D8`、洋红 `#FF00AA`、纸白 `#E8E8E8`、暗底 `#0A0A0F`。
- 第三幕新增一种专属色（青绿 `#3DFFB0`），只用于复活的节点与希望段的引导线。
- 纹理做低分辨率 + 点采样（Point filter），后处理叠扫描线、轻微色偏与暗角。
- 光照以烘焙为主，节点亮度用 emissive 驱动，不靠实时光照堆叠。
- 全片亮度上限在第一幕，第三幕不超过它——避免把「希望」做成年末促销。

## 听觉规范

- 音乐：原定素材为 FC14，用模块渲染 48 kHz WAV，正式播放不采用二手 MP3 转录；行号与音符事件作为卡点源。一个逻辑循环 256 秒，已有试听 WAV 多出下一循环约 0.1 秒，最终母带需按 [spec/14](14-fc14-music-visual-score.md) 处理并对拍。
- 环境层：拨号上网握手音、硬盘寻道、机箱风扇、键盘与鼠标点击；音量压在音乐之下约 −18 dB。
- 关键音效与音乐小节对齐：节点熄灭、弹窗落下、复制粘贴、计数器归零。
- 空间中放置少量「声音锚点」，自由漫游时能听出方向，但演出模式下不做体力化的耳机式定位。

## 玩家路径与交互

1. **演出模式**（默认）：进入世界后按开始，玩家沿轨道走完全片；可随时坐下观察，不可跳过段落（导演模式下可跳）。
2. **自由模式**：全片结束后解锁，玩家可以走遍四条动线，靠近任何节点读它的卡片。
3. **导演模式**：实例主（或指定用户）可暂停、跳段、重播，用于录制与调试。

多人同步原则：只同步「段落号 + 段落开始时间戳 + 节点状态位」三样。逐帧参数、粒子、后处理一律本地推算，不占用同步量。

## 空间性能预算（PC 优先）

- 节点用同一套几何体 + 材质变体，尽量走 GPU instancing；总三角面数控制在 5 万以内。
- 材质按状态分组，减少材质实例；纹理不超过 2048，全部 2 的幂。
- 玩家可见的独立音频源不超过 4 个同时播放。
- 弹窗墙、issue 洪水等「大量物体」段落使用粒子或合并网格，不用几百个独立 GameObject。
- 第一版不做 Quest 兼容；若需要，第三幕的粒子与后处理是第一处要砍的东西。
