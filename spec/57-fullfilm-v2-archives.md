# 57 全片 V2 过载段历史页面与公开图像来源

日期：2026-10-17。本文承接 [25 全景场面细化](25-panorama-scene-treatment.md)、[49 全片制作](49-fullfilm-production.md) 与 [51 过载模块](51-fullfilm-overload.md)，把用户提出的“133.12—186.88 秒信息量至少翻倍、增加真实图片与国内互联网材料”转成可核查的史料补充方案。机器可读索引为 [`data/fullfilm-v2-archive-materials.json`](../data/fullfilm-v2-archive-materials.json)，展示图在 [`art/reference/fullfilm-v2-archives/`](../art/reference/fullfilm-v2-archives/)；下载与哈希入口为 [`tools/download_fullfilm_v2_archives.py`](../tools/download_fullfilm_v2_archives.py)。

## 计数与来源状态

上一版基础素材共374张，本批不重复计入。新计数以独立的原页面或原图为单位；同图裁切、缩放、拼图、重复捕获日期和同一文件的CDN变体都不增加数量。首页、新闻页、论坛目录、软件目录、视频分享、社交入口分别记为来源项目，具体来源及页面类型见 JSON。

本索引现有52个不同的 `source_url`，全部成功保存为 PNG 展示副本，未计入前版374张基础图像。主代理与另一份公开媒体来源包核对后，当前合并来源池有66个唯一URL；合并计数不把同一作品的裁切、尺寸变体或相同来源重复图算作新项目。52张图全部来自 Wayback 捕获 HTML 的本地渲染，**不是**52张当年电脑的原始屏幕截图，也不是原图文件许可清单。

下载成功与展示完整度分开统计。离线页面检查结果为：26张主要版面可辨，其中2张已模糊普通用户账号；7张将用户正文、个人博客或具体作品详情遮盖，仅保留页面框架；8张版面不完整或只剩局部框架；11张主要是登录、搜索、托管或目录入口。太平洋电脑网论坛捕获只留下框架侧栏，应作为记忆碎片辅图，不能称为完整论坛界面。逐项状态见 JSON 的 `visual_quality`、`atlas_recommendation` 和 `rendering_limitations`。

来源覆盖国内门户、论坛、邮箱、博客、软件目录、字幕检索、游戏与视频分享，也包含 AltaVista、Napster、LiveJournal、GeoCities、Flickr、Orkut 等国际网页服务。更完整的页面/来源映射见 JSON，而不是把不同产品统称为一种界面。

## 图像完整度与适用范围

52张图中有26张的主要版面层级可辨。24张未遮挡内容的例子包括新浪、网易、QQ、搜狐、Yahoo!、CSDN、cnBeta、中关村在线、ChinaUnix、21CN、中华网、新浪邮箱、AltaVista、LiveJournal、Angelfire、4399、7k7k、电玩巴士、多特、BBSland、新浪论坛和3DM；色影无忌、ITPUB两张也保留论坛版面，但已模糊在线用户与版主/最后回复者账号。这里的“主要版面可辨”只描述静态结构和文字栏目的可识别程度，不代表完整恢复了每张图片、CSS或脚本。

8张只适合作为次要层或记忆碎片：天极与天空软件站捕获版面断裂；YouTube、中文eMule、Napster、17173和51CTO仍缺大量远程资源；太平洋电脑网论坛捕获只留下左侧框架。11张主要是入口或文本目录，包括开心网登录页、射手网搜索入口、又拍网注册/相册入口、Google搜索、MySpace、Friendster、Flickr、Orkut、西祠频道目录、土豆视频目录和BitTorrent文字页。

7张已遮盖个人内容或具体资源，只保留版式上下文：猫扑成人/营销话题、VeryCD具体影视条目、凯迪论坛帖子、博客中国/BlogCN/搜狐博客/博客园个人内容。不要把遮盖区当作原站留白，也不要以这些展示副本引用被遮盖的正文。完整的画面质量分类与逐项建议见 `visual_quality`、`visual_review_note`、`atlas_recommendation`。

## 日期、截图和存档页状态

`source_date` 只表示来源页面或报道可确认的发表日；首页没有单篇发表时间时留空。`depicted_year` 表示该次旧页面状态所处的年份。`capture_date` 是 Internet Archive 对原始网页的捕获时间。`screenshot_date` 是本地静态展示图生成时间。新闻正文所述事件日、页面发布日期、Wayback 捕获日和本地截图日期分别记录，不能互相替代。

全部页面图在2026年由 Chromium 将 Wayback 保存的 HTML 在本地离线静态渲染。渲染时阻断所有网络请求、禁用脚本，并移除 iframe、object 和 embed，避免把当前网站资源或现代插件错误带进历史画面。原始 HTML、原始离线渲染图与处理前版本保存在 `~/tmp/vrc-old-web-map/fullfilm-v2/archives/`。因此图像框、缺失 CSS、字体或 Flash 占位只能说明本地没有载入这些资源，**不能据此断言 Internet Archive 的存档也缺失资源**。本地展示图旨在呈现存档 HTML 可见的结构，不冒充完整历史浏览器状态。

9份展示副本执行了内容遮盖或账号匿名化：ITPUB 和色影无忌模糊了普通用户/版主账号；猫扑、凯迪、博客中国、搜狐博客、博客园与 VeryCD 遮盖了匿名帖子、个人博文、作者信息或具体作品/资源详情。未处理存档仍保留在临时目录，但不应进入最终图集。遮盖后只将保留的导航、栏目和版面关系用于辅助层，不将隐藏正文当作可阅读史料。其他论坛页未显示普通账号时，仍应以 `anonymity` 字段逐项核对。某个页面捕获存在，不证明它代表全站用户、全网流行度或其他同名平台；帖子标题不自动构成事实结论。

## 过载段的使用建议

过载段总长53.76秒。建议用多层页面建立“信息源显著增多，但出处、可用副本和有效回应难以辨认”的变化。主视线每次仍留一个可读焦点，侧层和远层提供可回看的页面、版块、标题与发布日期。可以按下列分工选材：

| 时间 | 史料作用 | 推荐处理 |
| --- | --- | --- |
| 133.12—143.36 | 前段作品与出处再次出现，来源和署名开始分离 | 先完整给一次来源/作者区域，再让独立副本进入外围；不要把一张截图复制成多份后计为新史料。 |
| 143.36—153.60 | 门户新闻、搜索目录、论坛首页、视频和分享条目同时靠近 | 新浪、网易、搜狐、QQ、cnBeta、ZOL、Yahoo、MOP、Xici、土豆和VeryCD可提供不同页面结构；文字抽取为独立原生字段，让标题、站点名、日期可分别显隐。 |
| 153.60—163.84 | 找到可用材料、排队维护、尝试回应 | CSDN、ChinaUnix、天空软件站、射手网及分享索引适合表现分类、版本、帖子和检索入口；真实处理队列与成功回应仍需由场面动画表达，不把页面布局误说成实际维护案例。 |
| 163.84—168.96 | 短暂冻结后，熟悉页面布局返回而内容尚未响应 | 用原创加载/等待文字与旧版页面框架分层；原创等待提示须标为演示文字，不伪造成某站历史通知。 |
| 168.96—182.40 | 文件可见、图片失效、入口访问受阻等不同状态 | 将文字、图片、播放器与登录入口拆成不同对象；分别表达“正文可读”“图片未取回”“入口暂时不可达”，不画作所有副本永久删除。 |
| 182.40—186.88 | 重新导入、接口适配与继续制作 | 回到工具、版本和来源说明，表现恢复需要检查，不以单一修复动作宣称所有历史页面都已复原。 |

用户要求过载段信息量至少为上一版两倍。素材侧已新增独立来源池；运行时仍须由主代理根据最终画面排布统计可辨识的内容单元。建议比较两版“独立来源卡、不同标题/时间字段、不同可用状态”的数量与持续可读时间，不能用增加重复卡片、裁切或缩小字号来冒充翻倍。完整文字可以留在演后索引里，播放时采用标题、站点、年份和状态等少量原生文本区域动态拆分。

## 可复现入口

```text
python tools/download_fullfilm_v2_archives.py
```

脚本从机器可读索引读取页面或原图来源，下载成功后生成展示副本并记录捕获时间、本地截图日期、尺寸和 SHA-256。请求失败会以 `download_status=failed` 和错误原因保留；脚本不会把页面 HTML 本身计为图像。原始页面和未处理图保存在临时目录。下载脚本只负责素材获取与索引，不操作 Unity 场景或任何序列化资产。
