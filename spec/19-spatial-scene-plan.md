# 19 三维场景规划：无界空间与空间关系的超越

## 两种空间体验分别成立

**无边界：观众找不到包住整体的房间、场地外框或可辨认尽头。** 内容可以在前后、上下与远处延伸，局部窗口、设备和活动仍有自己的轮廓。

**超越空间：已经建立的尺度、内外或远近关系发生变化。** 小窗口内部容纳更大的空间，进入之后原先的外部成为另一个小屏幕内的内容，原本远处的工位通过连接变为近处可共同操作的位置。

主结构改为：具体载体 → 撤去全局容器 → 长段无界的创造与传播 → 无界空间中过载和骤空 → 在无界环境中重新回应 → 超越局部/整体和远近关系 → 保留人尺度协作，外围继续无界。

连续空间演出新增主路线建议：人物保留独立参照，整体平移、旋转和缩放周围原生三维场景，让原地观众感到靠近、进入与穿行，详见 [20 世界运动演出](20-world-motion-performance.md)。稳定支撑与接触道具按状态分组，主音乐不自动挂在景物运动组；内外互换在整体运动下另用局部分组与遮挡接续。摄像机画面覆盖视野降为特定短段备选。

## 候选时间组织

以下时间依据现有序列段安排，未认定为原曲已有曲式或用户已定卡点。七段剧情与 256 秒音乐时长保持原样，空间阶段可以跨过剧情分段。

| 时间 | 空间体验 |
| --- | --- |
| 0—30.72 秒 | 有边界的电脑、手机、浏览器与工作室，建立身体尺度和年代 |
| 30.72—51.20 秒 | 撤去房间外壳与可见地面边沿，画面内外层次逐步展开 |
| 51.20—133.12 秒 | 主无界段，连续约 81.92 秒；活动片段分布到不同距离和高度，局部入口出现，外围仍无界 |
| 133.12—186.88 秒 | 无界空间里的过载；压迫来自副本、重复、尺度和遮挡 |
| 186.88—197.12 秒 | 无界空间骤空；远处仅照亮一个保存物，短暂隔离仍为候选 |
| 197.12—215.04 秒 | 无界环境中先出现具体回应，资料、AI 与同伴使合作重新启动 |
| 215.04—235.52 秒 | 约 20.48 秒的空间关系重构候选，内外互换、远近折叠 |
| 235.52—256 秒 | 回到可操作的人尺度，外围保持无界，交接与新创作继续 |

前段主无界窗口约一分二十二秒；再兴至片尾另有约 58.88 秒保持开放的外围，其中包含空间关系重构段。过载和骤空也延续无界基底，但既有 151.04—153.60 秒短视野替代若采用，仍按其独立范围验证。

## 无界空间具体长什么样

房间墙、天花板、方形舞台边缘和分区围合逐渐退出画面。旧桌面底色、浅色或幽暗背景均可延伸成没有可辨认终点的环境；色彩与时代内容按 `spec/18` 保留，黑色星空不是统一前提。

页面、文件、译稿、字幕、世界入口与人物活动成为不同深度的片段：近处有人操作，中景有交换与共同活动，远处仍有更小、更稀疏的内容。上方和下方也有层次。远景通过密度、尺度和消隐接续，避免显露硬截断或完整封闭穹顶。

制作、发布交换与共同活动继续作为行为分工，但不固定成围绕同一院落的三间房。各区的桌、设备、演员与图层可拆成局部片段重新摆放，关键注意力锚点随段落交接；不要求四分钟都盯同一个工位。

浏览器仍有自己的边框，某个许可入口仍可能挡住一项操作。外部无界与局部使用条件可以同时存在，繁荣、限制和过载由人与内容的关系区分。

## 超越空间怎样服务再兴

推荐将主要空间超越安排在再兴段：资料与 AI 降低开始的成本，传播使人找到同伴，具体协作让原来隔开的工作接续。空间关系的变化跟随已经发生的帮助和能力变化。

| 候选时间 | 画面动作 | 空间关系 |
| --- | --- | --- |
| 215.04—220.16 秒 | 远处工位在手边小窗内显现，近处与远处同时可辨 | 小窗内部容纳明显超出外壳尺度的地方 |
| 220.16—225.28 秒 | 经物件遮挡或布景接续进入窗内，原先外部又出现在新的小屏幕中 | 内外互换，局部与整体关系改变 |
| 225.28—230.40 秒 | 远处同伴成为近处共同演示者，一处操作使两端作品响应 | 远近折叠，由连接带来共同操作 |
| 230.40—235.52 秒 | 成果展开为新用途，再交给另一人 | 在改变过的关系中回到人尺度，外围仍无界 |

首版可以先用原生立体几何、复制布景和短遮挡切换检验内外互换，再决定真正窗口内立体呈现路线。后者的分眼、遮挡和深度必须验证，不将无限递归传送门作为已实现能力。

进入过程可由窗口及内部场景靠近、放大和经过观众来完成，人物保持人体尺度与自然观察；小窗外壳与内部空间作为独立子组，不能仅靠一个全局变换自动获得所有内外关系。远处工位接近后先停靠对齐，再完成演示与操作。

这段与过载时的短视野替代分开，默认保留自然的头部观察反馈与实际双眼深度。验收应能辨认原来建立的内外、远近或容纳关系已改变；单纯放大屏幕或普通换房间不足以完成这个目标。

## 后台几何与观众所见分别规划

前轮 32×28 m 主地面、6×3 m 构图区、八个观察点以及制作/发布/共同活动的初始坐标，降为支撑、排练与演后局部可达区域的候选。它们不是可见场地尺寸，也不是世界最大人数或固定座位。

无界段使用不可见支撑，或不露出边沿的连续基底；实际支撑和有限渲染存在于后台。有限的可达区域和有限素材也可组织成无界观感，当前不承诺无限几何或无限可行走地图。背景面片、通行地面和玩家落点分别管理。

正常大小器物仍可提供操作参照；多人必读内容使用保留完整机身或软件版本边框的放大载体。早段原型在后段可以迁移、改变尺度或作为入口，旧内容的年代样式保持不变。演员与每幅画面的内部拆层沿 `spec/17` 继续制作。

## 过载、骤空与继续

过载发生在仍然无界的环境中，复制品和请求从远处与周围增殖，局部遮挡挤占注意力。近景撤去后，同一片无界空间可以变得冷清，远处约 18 m 的一个保存物被单独照亮。独处小景的局部坐标和隔离空间不应成为可见房间外壳；若隔离路线未验证，共享落点也保留无界留白。

再兴在局部人尺度操作中建立一次成功，随后发生空间关系重构。结尾可以有桌、可达的地面片段、资料点和真实接手动作，外围保持开放无界。片尾“那就一起做下去。”出现时，作品和新贡献继续有去处，不重新封回第一轮的固定公共场地。

演后可以进入局部真实可达的工作与阅读区域；是否进一步开放漫游，以及实际容量，待场景原型明确。

## 声音原则保持

无界视觉不要求四音乐声部全周环绕，常态仍以前方融合为基线，环境和动作声可以分布各处。原两处短高潮依旧未正式启用；再兴的空间关系重构不自动增加第三次明显分轨。

若内外互换、独处与恢复改变了视觉落点，音乐的前方参照和声音位置也随本地演出坐标安排，保留同一音乐时基。具体听觉切换和多人恢复须验证。

## 灰盒优先级

1. 先验证人物、支撑、世界运动组和接触道具的关系，完成靠近、进入、停靠、操作与离开；随后检查房间撤界和连续约 82 秒无界体验。
2. 在同一无界基底中检验繁荣、局部阻力、过载与远处单灯，检查不同观众位置的关键动作与阅读。
3. 用约 20 秒的再兴片段单独检验内外互换、远近重构及声音位置，保持自然双眼和头部观察。
4. 最后安排人尺度协作、接手动作与局部演后可达区域，补充复用美术和精细动捕。

进行 Unity 灰盒时遵循 `UNITY-GUIDE.md` 与 unity-pipeline skill，序列化内容走 Pipeline。本轮仅修改规格、数据与规划示意，未操作远端工程。
