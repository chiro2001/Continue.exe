# 35 原界面的拆层操作

在三处关键段落，以已有完整历史图为参照，把同一界面的框、内容、图标、音频、预览和时间轴拆成有前后距离的部件。裁切只是同一内容的表现层，不计入 355 项独立素材。

| 区间 | 参照 | 动作与结果 |
| --- | --- | --- |
| 10.24—20.48 | Windows 98 SE Explorer 真实截图 | 选中文件、拖出文档、README 展开并逐字写入，18.88 秒完成；正文为本项目原创演示，保留“工具也有作者”的含义 |
| 40.96—51.20 | Aegisub 真实主界面与文档预览图 | 预览、音频、时间轴、台词分层；游标依 80ms 行时钟移动；44.16 秒仍有错字，44.40 秒修正；50.46 秒后呈现八行校对与 ASS 导出结果 |
| 51.20—61.44 | BT 区块的原生三维表现 | 四节点提供/请求，16 块按具体起音先后抵达，57.60 秒合成完整文件；58.24 秒后继续上传，61.29 秒最后一个包抵达 |

BT 收片触发具有 .16/.32/.48/.64 秒等不同间隔，逐项对照原 `tracks.csv`。该段 CH02 没有新起音，不伪造均匀鼓点；保留真实持续声部和节点提供关系。字幕校正、README 正文与发布文件名都是演出创作，不冒充历史原文。

`OWEpisodeV3Operations.Build()` 在 Pipeline 中持久化对象、材质、网格、字体与引用；`OWV3Operations` 自行读取导演时钟，公开 `Sample/Seek`，主集成离线采样也调用它。部件使用独立裁切 Shader，字幕小波形复用实际 PCM 图集与 ribbon Mesh，音源位置仍由主示波器统一负责。

三组仅在各自时段出现，中心约 `(0,2.4,6)`，避开头随字幕与两侧人物。同期主图和原创操作窗口退到左右/后方，快速记忆闪回短暂掠过，主次由动作决定。

观察点：11.6/13.6/17.2/19.2 秒的选择与拖拽；43.52/44.16/44.64/50.8 秒的时间轴与修正；53.2/57.9/60.6 秒的传递、成片与继续上传。验证同时对照音符真实性、独占时段、反向 seek 同一结果、实际全片 Udon 与动态参考片。
