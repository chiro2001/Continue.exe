## 已确认的创作条件

- 作品是 VRChat 内的实时 3D MV 世界；「地图」是作品载体，内容不必是一张地图。
- 主题包含网络技术共享精神的没落，以及 AI 等新工具降低修复和互通门槛所带来的希望。
- 以用户指定的 Keil 经典注册机音乐为目标，保留主线与不演唱的歌词线。实际音源、编排和总时长尚未定稿。
- 可使用任意数量的叙事人物，首批外观是 Kipfel 与 Nemesis，人物身份独立于外观。用户已有动捕设备，精细表演后续录制。
- 空间密度、尺度、距离、局部灯光、突然出现、观演环境与视点变化、短暂视听分离及视觉固定都可以参与表达。具体实现按 `spec/08` 验证。

## 核心立意

一份来自陌生人的帮助，如何穿过失效的链接，抵达后来的人。

共享依靠人愿意交出成果、接收者承认来源，以及有人继续维护和回应。内容可以越来越多，人与人之间的联系却同时减少。后来的工具让继承者有能力继续部分未完成的工作，保留下来的代码、文档和署名因而再次发生作用。

前段让观众得到一次具体的帮助；中段看见分享者承担的成本，并亲身经历失联；后段由受助者或后来者接起这份工作。AI 的作用通过阅读现存资料、生成补丁、验证互通和旧设备/程序重新响应来表现。

当时题名曾沿用《世界地图 / World Map》作为工作名；现世界名已定为 **Continue.exe**。「请留一份给后来的人」作为当时的结尾句候选保留。

## 人物与观众

建议采用社区群像，以几位反复出现的人承载情绪记忆：

| 角色职能 | 贯穿变化 |
| --- | --- |
| 留下东西的人 | 起初分享作品和工具、回应求助；后来承担维护与信任成本；最后其文档、代码和名字仍被保留 |
| 得到帮助的人 | 从接收者变成分享者；失联后保留了一份本地副本或资料；参与重新接通旧项目 |
| 后来的人 | 借助现存资料与新工具接续工作，得到能力后把成果再交给别人 |

上述职能可重叠或由不同年代的人接力，不强制三名演员，也不指定 Avatar 对应哪个角色。其他人构成真正有各自事情的社区：制作、查阅、等待、转交、使用、求助和离开。

观众是一位到访社区的人：既观看 NPC 表演，也亲身经历与同伴共处、受阻、分离和重聚。关键情节依靠确定的演出事件推进，真人观众是否开口、转头或触发物体不影响叙事完成。

## 七个连续场面

篇幅是讨论用比例，合计 100%；实际秒数待音源和编排确定后再对齐。

| 场面 | 篇幅 | 内容情节 | 情绪与空间 |
| --- | --- | --- | --- |
| 1. 收到回复 | 7% | 一个人遇到困难，另一处有人送来一份带署名与 README 的工具/项目。运行成功后，接收者抬头回应，分享者才放心离开 | 小、近、安静；先见到人和一次帮助，启动文字作为局部细节 |
| 2. 房间连成社区 | 22% | 接收者又帮助下一个人。相似的交换在许多房间发生，有人创作模型，有人写教程，有人维持服务。几位人物在不同位置反复出现 | 情绪高点；墙向外展开，房间在前后左右与上方出现，文件从身边经过；空间密集但关键动作清楚 |
| 3. 入口还在，路开始断 | 16% | 收藏的链接失效、下载反复等待、共享入口加上条件。人物仍想交流，抵达彼此的成本越来越高 | 从小挫折积累到烦躁；手边窗口长成门和建筑，进度条延伸为长廊，弹窗挤占同伴之间的视线 |
| 4. 热闹背后的人 | 20% | 来到维护者桌旁：请求持续抵达，回应逐渐迟缓。另一位创作者的作品被机械复制，署名脱落；复制品继续运转，原作者退出，维护者停下工作 | 压迫高点；内容密度甚至超过第二场，人物之间有效的回应却越来越少。音乐可保持熟悉与明快，动作和界面变得机械 |
| 5. 还在线，却联系不上 | 12% | 关闭/失效的窗口短暂占据固定视野，转头也无法避开。随后窗口退去，每个观众各自留在空旷环境里，同伴的视觉与声音暂时消失 | 先窒息，后骤空；给予一个短暂、可感到停顿的低点。远处仅剩一处局部灯光和旧项目的痕迹 |
| 6. 接起未完成的工作 | 18% | 受助者保留的副本、README 或档案成为起点。后来者借新工具读懂旧接口，尝试、修复、验证；开场出现过的程序/设备再次响应，修复结果被送往另一间房 | 希望有具体的因果和完成动作。先听到一次确定的操作与响应，再出现人物、灯光，逐步恢复共同空间 |
| 7. 新回复 | 5% | 新来的人得到帮助，再把成果留给下一个人；旧作者的名字仍在，新的贡献者追加署名。出现一条新回复，演出结束后社区空间继续可停留 | 有余温的开放结尾；部分座位仍空着，远处仍有未亮的房间。回升到能继续生活和交流的程度 |

中心道具的具体内容仍待讨论，建议使用可运行的小工具/项目及其 README；通过可观察的设备或窗口响应证明它重新工作。网盘、开源和 VRChat 三组素材是同一社区所经历的障碍、维护成本与信任破裂，转场通过人物、道具和动作衔接。

## 情绪节奏

总体曲线：好奇 → 得到回应 → 共享的快乐 → 烦躁 → 过载与窒息 → 空落 → 试探 → 一次成功 → 余温。

第二幕安排两个不同低点：先让物件、请求和副本过多，形成压迫；再突然撤空，形成孤独。两者之间用一次明确的空间变化连接。

希望段需要完成「发现遗留资料 → 使用工具进行修复 → 现实中的东西重新响应 → 把结果交给别人」，为这些动作留出篇幅。片尾延续恢复中的空间，不再把访客计数归零当作唯一结论。

音乐以真实音源为依据安排段落，不假定尚未取得的模块在某秒有特定 breakdown。情绪也由环境声、人物反应速度、运动密度和停顿组织；失联时仍可保留同一音乐时间线，撤去的是交流和环境层。

## 视觉语言

### 有人生活过的地方

近处有桌面、旧电脑、线缆、文档和人物习惯，人物之间能看见回应。旧网页元素与年代对应，从个人主页、自建目录逐渐进入云服务、仓库和 VRChat 的界面。

材料、光照、构图和相似的交换动作统一不同年代。低分辨率纹理、像素字和 CRT 只用于适合的媒介；人物和近处道具保留可读的三维体积。

### 密度与在场感分别控制

- 共享段：内容多、人多、互动多，自由观察的空间大。
- 过载段：内容更多、界面更亮，真人的回应更少，构图逐渐被挤压。
- 失联段：内容极少，远处的灯与很大的距离成为主体。
- 修复段：内容少而具体，人之间再次有响应，空间逐步重新打开。

### 尺度与视野变化

先建立手、桌椅和人物的尺度，再让窗口变成建筑、请求占据头顶、复制品扩展到远方。短暂固定视觉用于「入口封闭/无法回避」的高潮；解除时，眼前界面退回空间中的一个物件，观众重新能够转头看见同伴。

局部视点变化用于靠近维护者和进入旧项目留下的空间。密集、尺度突变、视觉固定、视听分离各有情节功能，具体强度由原型决定。

### 调色与光

初段以屏幕的暖光、米白与有人使用过的材料建立体温；中段逐渐加入冷白和蓝灰的标准化界面。压迫高点可以保持很亮，空落段才撤去大部分光。

希望段用少量新颜色标记新接上的部分，保留旧材料、原作者署名和修补痕迹。恢复后的社区有旧与新的差异。

## 表演与声音

反复使用「递出—等待—接住」作为动作母题；精细停顿、重心、迟疑与疲惫留给后续动捕。角色反应会改变同一个动作的含义。

群体各自有事情，背景动作可复用并错开相位。主动作附近保持更清楚的轮廓与响应，观众转头则能发现补充内容。

剧情转折以预制操作声、人物动静和设备响应保证可发生；真人语音作为现场感。失联段分别管理玩家语音、Avatar 音频与场景环境声；修复后逐步恢复。

## 歌词线、史料与署名

保留不演唱的歌词线，文字提供画面之外的个人感受。以下是重新写作的候选句，不覆盖旧 `data/lyrics.json`：

> 你留下一份，我因此走到了这里。
>
> 我也把它，交给从未见过的人。
>
> 那些链接，曾经通向一个人。
>
> 窗口还在亮，回答的人越来越少。
>
> 文件传得更远，留下的名字却更少。
>
> 我终于修好了它，却不知道该把消息告诉谁。
>
> 于是我把它，留给下一个经过的人。

greetz 与作者名可以在共享高点和修复后的接力中出现。最低点留出画面与声音的空隙。史料只选少量经过复核的事实锚点，虚构人物的表演不能被当成真实当事人的经历；`data/quotes.json` 中待复核条目仍待复核。
