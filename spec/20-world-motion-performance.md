# 20 世界运动演出：人物保留参照，场景经过观众

状态：2026-10-16。用户提出移动、缩放和旋转人物以外的场景，使站在原处的玩家像乘观光车一样进入三维场景。本稿建议将此作为进入、穿行与尺度变化的主要路线；具体轨迹、分组和参数为演出/实现候选，尚未在 Unity 或头显验证。数据见 [data/world-motion-plan.json](../data/world-motion-plan.json)。无界与空间超越沿 [19](19-spatial-scene-plan.md)，剧情、风格和音乐原则保持。

相对运动示意：[可交互页面](/home/chiro/tmp/vrc-old-web-map/world-motion-20261016/20-world-motion.html)。可调整场景平移、偏航与统一缩放，观察人物和支撑参照。它是脚本绘制的单眼结构示意，不是 Unity、真实 Avatar 或头显测试。

## 原生空间中的相对运动

观众维持本来的头部、手部与身体追踪，人物保留人体尺度。实际几何和分层面片在周围经过，左右眼与侧移观察仍由真实空间关系产生。

向前穿行可以通过场景反向平移表现；转向可以通过场景绕共享枢轴旋转表现；小窗口、设备或作品逐步变大，内部场景靠近并经过观众，可以表现进入其中。多种局部景物以不同深度经过，形成近快远慢的运动关系。

“观光大巴”在这里描述共同的观演参照和连续旅程，不要求出现实体车厢。无界段可隐藏整体载具、房间或舞台外框，必要的脚下支撑保留在后台。

## 参照分组

| 分组 | 成员与行为 |
| --- | --- |
| 人物与稳定支撑 | 真实玩家保持 VRChat 原生追踪和实际位置；NPC 独立骨骼表演、走位；脚下支撑不随世界缩放。真实玩家不是可随意挂在自建 Transform 下的对象 |
| 运动场景 | 自绘面片、页面、建筑、景物、窗框、非接触道具及背景组成世界运动组，使用共享平移、旋转和正的统一缩放 |
| 局部场景组 | 整体运动之下保留窗口、内部房间、远处工位等独立子组，用于不同尺度、遮挡接续和内外互换 |
| 接触道具 | 手持、触碰或正在操作的桌面物件按表演状态进入稳定参照，交接时保持世界姿态；操作结束后再接回场景或收走 |
| 主音乐 | 四声部属于演出前方参照，按原音乐计划调度，不自动跟整片景物翻转、缩放或飞过头顶 |
| 环境、动作与光照 | 场景声跟随实际发声位置；人物/手持物声音跟随对应对象。人物基础受光和场景光分别检查 |

人物可以继续做动作和独立走位；排除的是把人物与整个布景统一放大、旋转和平移。图像内部绘制的人物作为内容素材随其画面运动，场景中的骨骼演员按人物分组管理。

## 整体变换与局部重构

场景整体可用共享枢轴 `a`、平移 `d`、旋转 `R` 和正的统一缩放 `s` 表达：

`p_display = a + d + R · (s · (p_source − a))`

枢轴属于共同演出坐标或当前入口，不逐帧追随某个人的头部。共享场景使用同一条演出曲线，不为每个头显各自转动整片世界。均匀缩放保留旧界面宽高比，画面内外的独立层级继续按原图对齐。

单个整体变换保留场景内部的相对结构。进入与穿行可先由整体运动完成；小窗容纳大地方、内外互换等更进一步的空间关系，结合局部分组、复制布景和遮挡接续制作。真正的递归窗口仍是另需验证的路线。

## 人与道具的接触

动作按“航行—停靠—操作—交接—再航行”组织。航行时人物可看、指、交流，接触道具保留稳定参照；需要编辑、按键或试用时，让场景减速停靠并把操作台与人物对齐。

桌子、屏幕、椅子和手持物若直接跟整片景物运动，可能破坏手、脚与物件的对应关系。因此“所有非人物一起动”在演出中需按接触状态分组：非接触布景跟随世界，身体正在使用的物件暂时独立。物件换组时维持当前世界姿态，再按动作过渡，演员的走位与触点随停靠位置编排。

实际碰撞和视觉几何分别管理。脚下支撑、玩家站点和人物本身不通过移动碰撞面被意外运送；正在经过的墙、门框和大物件按整个观众组的自然活动范围规划通道，不能只让中央视点看起来能通过。

## 放回当前演出

- **房间撤界与长段无界：** 人物参照保持，房间和载体外壳退出，页面和活动片段逐步经过观众身边，远处内容继续延伸。
- **繁荣：** 在不同内容片段之间连续穿行，靠近某项制作与发布，短暂停靠看见一次完成动作，随后继续前往下一组内容。
- **过载：** 重复内容和请求加密经过，尺度和局部遮挡增加压力；大范围视觉运动的强度另做头显调校。
- **再兴空间超越：** 当前 215.04—235.52 秒仍为候选。小窗口向观众靠近并变大，内部场景作为独立分组接续；进入后回收一个新的小屏幕显示原先的外部，再将远处工位送到可共同演示的位置。
- **片尾：** 航行逐渐减弱或停靠，回到可操作的人尺度，外围保持无界；交接与新想法继续发生，片尾“一起做下去”保持。

摄像机画面覆盖视野保留为特定短段的备选，例如有意表现被关入平面界面。它不是连续进入三维场景的默认依赖；原 151.04—153.60 秒窗口不再默认执行，也不因本路线延长。

## 声音、多人和制作约束

主音乐维持前方融合与少量高潮展开，沿用同一四轨时基；世界运动不自动改变四源参考或新增高潮。环境和动作声跟随发声物位置，音量/作用范围分别校准，Transform 缩放不自动等于空间音频参数按同比例改变。主音乐多普勒先关闭。

建议共享阶段与演出时间，由各客户端重建相同世界运动；中途加入、重播、暂停与恢复均需检查状态。视觉曲线的节拍尺度不能当作音轨同步容差。

先用平移、缓慢偏航与均匀缩放检验路线；加减速、俯仰、横滚和大幅运动的效果要在头显调校。自然头部追踪和原生双眼深度成立，并不自动证明大范围视觉运动适合长时间观看。

移动布景的烘焙、静态合批、反射与阴影配置需按实际管线核对，不假设现成房间可以直接整包挂到运动组。自绘内容和简单模型按可见范围分组；人物基础照明与环境的运动光照分别组织。

## 首个验证片段

用稳定人物占位、隐藏支撑、一个窗框和一间简化内部场景，完成“靠近—进入—停靠—操作—离开”。依次检查：人物尺寸与原生观察、全组通道、图层深度、手脚接触、音乐前方参照、环境声位置、多人同视与重播恢复。

完成这组原型之后，再把轨迹放入约 82 秒的无界段与约 20 秒的空间超越段。本轮仅完善规格和交互示意，不操作 Unity 工程。
