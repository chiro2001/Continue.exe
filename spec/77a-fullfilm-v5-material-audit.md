# FullFilm V5 素材与年代审计

本页记录 V4 素材在 V5 时间轴中的重点错置、八张用户自绘图的当前用途，以及新的论坛→贴吧表情版本组。机器可读记录见 `data/fullfilm-v5-material-audit.json`，可直接绑定的表情文件清单见 `data/fullfilm-v5-emotes.json`。V5 时间戳来自本地时间轴数据与源码采样逻辑；本审计没有操作或验证 Unity 场景。

## 年代修正

V4 基线把 1999、2009、2010、2012 和 2014 的材料混在较晚的 `conditions` 或较早的 `translation` 焦点里。V5 的 `chronology_override_cues` 已按源内容把重点事件排回对应年代；这些数据修正还需要主代理在 Unity 中导入并实看。
