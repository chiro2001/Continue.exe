## 当前主方向

**先按年代、设备与软件还原内容，再适度调色；载体从具体屏幕和窗口，逐步展开为可进入的三维空间。**

年代外观与空间自由度分别设计。一个旧浏览器在后段可以放大、脱离电脑并长成入口，仍保留自己的边框、按钮、字体和像素结构。新的内容按自己的年代呈现。原样式与后期空间变化共同构成全片，而不是按段落把所有旧内容换成当代风格。

具体三维拓扑与观众位置推荐草案见 [19](19-spatial-scene-plan.md)，本稿的年代外观与载体递进作为其已有约束，具体场地尺寸和转场仍待细化。

最新空间约束包含长段无界以及一段空间关系超越：旧内容的局部边框保持真实，外围不由整体房间或可见舞台边沿包住；再兴段候选用小窗与大场景、内外互换和远近重构深化自由度。明亮底色、旧桌面色与幽暗背景均可表达无界，具体候选时窗以 `spec/19` 为准。
美术风格回答形状、绘画、字体、材质与色彩如何呈现；画面风格回答这些内容怎样占据空间、受光、遮挡、运动和吸引注意。前者允许不同年代与内容家族拥有各自审美，后者用稳定的尺度、层次与注意力组织形成全片的一致性。

面片是制作方法。它可以呈现发光屏幕、塑料标牌、纸页、平涂插画或分层小场景，表面性质按内容确定。纸张质感集中在真实纸页、便签与漫画等对象。

## 美术倾向

| 对象 | 建议处理 |
| --- | --- |
| 历史界面与网页 | 以具体系统、浏览器版本和设备为参考，还原布局、标题栏、边框、按钮、图标、文字与像素尺度；原始引文与重建内容保持身份区分 |
| 原创演示与插画 | 轮廓简洁、色块明确，按同一画面的前中后景分别绘制；允许像素画、涂鸦、漫画和精确矢量排版存在于不同内容家族 |
| 简单模型 | 保留主要轮廓、少量倒角和必要厚度；塑料、木材、金属和纸各有简单受光，细节优先来自贴图与标识 |
| 演员 | 保留 Kipfel/Nemesis 等现有 Avatar 的辨识度，用场景曝光、局部色彩与接触关系帮助融合；图中简笔人物仅为构图占位 |
| 复用环境 | 挑选必要家具与生活物件，控制纹理噪声和装饰密度，灯光与主体内容协调 |
| 线条 | 界面边界和插画轮廓清楚，实体按自身形状受光；是否描边依对象家族决定 |
| 分辨率 | 旧 UI 在对应的虚拟像素网格中制作，保留原字体栅格和整数对齐；插画、演员与当代内容按自身性质保持清晰，采样按显示距离验证 |
| 特效 | 光标、GIF、按钮、分块与局部响应承担节奏细节；故障、发光、CRT 扫描线等按来源、物体与剧情局部使用 |

## 年代文字与像素结构

“老 UI 的像素感”来自具体字体、字号、像素网格、渲染设置、系统主题和显示载体。先建立对应分辨率的界面，再作为屏幕或分层面片呈现；主要控件与文字优先按整数像素对齐。放大载体时保留这一图形结构，阅读尺寸通过载体大小、距离和构图安排。

技术校准：Windows XP 已支持字体平滑和 ClearType，更早的部分 Windows 配置也支持字体平滑，不能把 XP 及以前一律记为只能显示无抗锯齿点阵字。XP 年代的小字号中文界面常见内嵌点阵效果，但具体表现仍与字体、字号、应用及设置有关。制作时分别参考位图/点阵字、灰度抗锯齿或 ClearType 的实际样本，不把一种栅格效果套到全部系统、网页或手机。

CRT 屏幕可按需要表现轻微辉光、扫描或弯曲；液晶显示器、按键机和早期智能手机采用各自的显示性质。轻微滤镜作用于指定屏幕或内容组。当前不对演员和整个 VR 视野统一像素化。

## 载体怎样逐步展开

前期同时使用两类边界：电脑/手机的实体屏幕，以及系统/浏览器的软件窗口。手机素材按设备与年代分别设计菜单、软键提示、按键区、触屏控件、宽高比和页面布局；桌面网页与 WAP/移动页面各用对应版式。按键机与早期智能手机的外壳进入简单模型候选。

| 递进阶段 | 呈现方式 | 与当前演出的关系 |
| --- | --- | --- |
| 载体内 | 内容先在电脑、按键机、早期智能手机屏幕或清楚的浏览器窗口内出现 | 接入段优先建立实物、窗口边界与像素尺度；两条文化史先从这些载体被看见 |
| 窗口展开 | 屏幕/浏览器逐渐放大，画面内部拆出景深，文件、图层和页面开始越过边框 | 繁荣段可逐步展开，仍保留可辨认载体，具体展开点随音乐细化 |
| 边界重组 | 旧窗口可以变成入口、建筑或挡路结构，保留对应年代的外观 | 条件改变和过载沿用既有情节，用空间关系表现具体阻力 |
| 远处锚点 | 大部分内容撤去，熟悉的旧屏幕、文件或作品成为远处局部亮点 | 骤空段维持留白和可辨认的保存物 |
| 自由组合 | 内容可以悬浮、拆层、拼装、跨越玩家周围并组成共同工作区，实体设备按需要保留 | 再兴与继续更自由；旧内容仍保留旧样式，新作品可有自己的当代表达 |

上述是已选载体递进方向下的演出建议，具体时间与空间范围不写成已验证参数。开场已经交织互联网与 VRChat，较自由的全空间展开逐步建立。

## 色彩与光照

前轮草图 A 的灰白、木色、蓝、青绿、灰紫与暖黄仅是旧比较图的配色记录。当前以对应年代与设备的真实配色为基础；可用轻微色彩覆盖、色温/明度调整或局部滤镜协调环境，保留主要系统色、图标和文字边缘的辨识度，具体强度待样张比较。

建议环境大面积采用中性或较低对比颜色，把较鲜明的颜色留给具体文化内容、人物和重要动作。正常工位可有暖灯、自然光、屏幕光等不同局部气氛，远处和侧方的亮度控制注意力；黑暗作为有意义的段落变化。关键界面通过稳定底色、自发光比例与局部照明保持可读。

繁荣的视觉丰富度来自多种内容同时成立。过载通过复制、遮挡、压缩和反复索取改变关系；骤空通过撤去近景、压低环境和远处单独照明建立距离；再兴通过一次具体回应和可共同工作的照明逐渐回升。

## 画面与空间组织

- **先有可辨认的身体尺度和载体。** 电脑、手机、工位、人物与明确的软件窗口先建立参照；随后放大、越出边框和组成场所，尺度变化才有分量。
- **主动作明确，周围有内容。** 前方保留一个必要动作与阅读面；中景有相邻活动，侧后与远景有可发现细节。观众转头可以获得更多内容，主要理解由核心动作保证。
- **场景之间与场景内部同时有深度。** 同一插画的前景、人物、设备、墙和远景分别绘制并拉开适量距离，前后遮挡在两眼与侧移中成立；正文与控件保持紧密可读。
- **细节快，主要动作完整。** 音符可以驱动局部提示，图层合拢、递交和操作保留完整过程，较大的构图与尺度变化按演出段落组织。具体音乐重拍仍待试听。
- **转场以形态和动作相接。** 字幕块接 BT 分块，网页边框接门框，桌面编辑接 Avatar/世界制作；跨年代的事实语境各自标明。
- **运动有不同层次。** 主动作明确，其余人物、GIF 与背景可以用不同周期保持生活感；高潮才集中增加整体运动和尺度。

## 同一主风格怎样承载七段

| 段落 | 画面组织建议 |
| --- | --- |
| 接入 | 电脑、按键机、早期智能手机或浏览器窗口承载对应年代内容，先明确边框与像素结构 |
| 繁荣 | 屏幕与窗口逐步放大、拆层和越出边界，多种年代内容在前中远景展开 |
| 条件改变 | 熟悉界面更规整，入口与待处理事项占据更多空间，具体阻力可辨 |
| 过载 | 重复、遮挡和放大挤压来源与选择，光照与构图的反差增强 |
| 骤空 | 大幅撤去近景，远处一个已见过的对象受光，保留原曲持续部分 |
| 再兴 | 近处先有回应，旧样式与新工具自由组合为共同工作区，照明随协作与新作品扩展 |
| 继续 | 更开放的工作空间中仍有人交接和创作，旧内容与新贡献并存，片尾“那就一起做下去。” |

人物数量与外观可替换，表演可以后续动捕细化；主音乐仍以前方轻微分层、整体融合为基线，只有少数候选高潮短暂明显展开。

## 前轮选项留档

B 增加手绘插画的比例，场景和道具更依靠笔触、色块和轮廓统一，整体偏柔和亲近。对照图仅以简化轮廓与色彩示意，正式手绘质感还需画面样张检验。

C 更强调抽象图形、冷暗空间、发光轮廓和几何阵列，空间秩序、疏离与压迫更突出。它也可作为某些段落的局部画面手段。

前轮 A/B/C 不再作为三个平行待选项。当前采用用户明确的年代还原与载体展开方向，手绘和抽象图形按具体内容与段落使用；旧稿统一终端配色及前轮简化界面不作为当前还原标准。
