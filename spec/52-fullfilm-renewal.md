## 实现接口与资源

- 运行时：[OWFullRenewal.cs](../unity/Assets/OldWebMap/Scripts/OWFullRenewal.cs)。`autoSample=false`；`Sample(float)` 与 `Seek(float)` 从绝对时间确定所有状态，不读本地时间、不随机、不创建对象、不改骨骼姿态。主调度统一调用；0 隐藏，255.96 保留演后工作区。
- 构建：[OWFullRenewalBuild.cs](../unity/AgentScripts/OWFullRenewalBuild.cs)。新场景必须是 `Assets/Scenes/OWM_FullFilm_v1.unity` 且停止 Play Mode，父根必须存在。仅重建自有 `FullFilm Renewal` 子树，不自动保存场景。
- 时间与人物：[fullfilm-renewal.json](../data/fullfilm-renewal.json)。六个独立角色表，80 ms 网格；旧角色动作与新人的先受助再助人有明确时点。
- 原创绘图：[draw_fullfilm_renewal.py](../tools/draw_fullfilm_renewal.py)，17 张导出在 `art/export/fullfilm/renewal/`。图形、界面、文字均为本项目原创；记忆帧来自已有 V5 实际渲染，不作历史资料。
- Unity 资源全部在 `Assets/OldWebMap/FullFilm/Revision1/Renewal/`，子目录 `Textures / Materials / Meshes / Fonts / Programs`。已有家具、Humanoid、动作与材质只读复用；实体书引用前半已制作的源。

主代理批量复制 `.cs`、JSON 与 PNG，统一 Refresh/编译之后，按顺序执行：

1. `OWFullRenewalBuild.Import()`：配置 17 张纹理。UI 保持未压缩和 mipmap；图层保留透明度。
2. `OWFullRenewalBuild.RepairProgram()`：仅统一修复程序未覆盖时使用。
3. `OWFullRenewalBuild.Build()`：持久化几何、家具、材质、字体、光、角色、独立道具与数组，`autoSample=false`。
4. `OWFullRenewalBuild.Validate()`：检查角色速度、近场距离、相互间距、回跳确定性与时窗。

停止态截图用主代理统一 Pose：先主呈现 Sample，按每位活跃演员的 `V4Pose/V4PoseTime` 运行 Animator.Update(0)，再 Sample 一次。本模块不会恢复骨骼或覆盖该定态。独立入口 `OWFullRenewalBuild.Pose(float)` 只是同一操作的便利封装。

重复构建需支持等待态父根隐藏：父根从活动场景的根对象列表查找，数值验证读取角色 `activeSelf`，不擅自激活呈现父根。新 TMP 标签先作为活动的临时场景根初始化，再挂到目标层级；直接在隐藏父根下新建 TMP 后立即赋 `font`，会在 `LoadFontAsset` 访问尚未由 `Awake` 缓存的 `m_renderer`。实际第二次构建已定位此异常到 `TMPro_Private.cs:526`，Builder 已据此修复。字体材质和 atlas 在填字前后持久化、标脏并保存，缺损时从 Noto 创建自有新路径；替换模块前先用临时活动标签做字体赋值和网格更新探针。
