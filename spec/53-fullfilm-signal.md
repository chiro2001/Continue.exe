# 53 全片信号、声源与气氛（Revision1）

日期：2026-10-17。延续 V5 的 256 秒完整版本；目标场景 `Assets/Scenes/OWM_FullFilm_v1.unity`，新资源仅在 `Assets/OldWebMap/FullFilm/Revision1/Signal/`。不改 V5 场景、运行时类、原有图集与材质。

## 入口与文件归属

- `unity/Assets/OldWebMap/Scripts/OWFullSignal.cs`：统一 `Sample(float)`、`Seek(float)`、`Waiting()`、`Finished()`。`autoSample=false`，由全片主调度调用。
- `unity/AgentScripts/OWFullSignalBuild.cs`：Pipeline 独立入口 `OWFullSignalBuild.Build()` / `Validate()`；只标脏当前全片场景，不保存。构建器不调用其他临时构建类。
- `unity/Assets/OldWebMap/Shaders/OWFullGreetz.shader`：保留 V5 正弦滚动字的几何与采样方式，新增整条劳动角色掉落、阶段裁切与孤立光标。
- `tools/prepare_fullfilm_signal.py`：复用未修改的 V3 PCM 图集生成器与 V5 字形绘制函数，输出 `data/fullfilm-v1-{waveforms,signal}.json`。
- PNG 与离线报告：`~/tmp/vrc-old-web-map/fullfilm-v1/signal/`。临时编译检查也在此目录，和 Unity 实测报告分开。

## 完整 PCM 与持续音

四条输入都是原始 256 秒、48 kHz、16 bit 单声道分轨。新图集 512×8192，30 fps、7681 帧，RGBA 分别存四轨真实采样；每列仍由连续六个样本平均得到，保留 AC 耦合、相位触发和共同 RMS 参考，不做每帧归一化。末端只给原生成器的向前探针提供 120 ms 零值后滚；没有改变输入 WAV，源哈希记录原文件。

`spec/48` 的音乐纠错是运行事实：163.84—166.40 秒 CH1/2/3、189.44—194.56 秒 CH2/3/4、245.76—250.88 秒四轨、250.88—253.44 秒 CH1/2/4 均有持续信号。tracker 音符闪烁只读 note-on；其电平条与波形取真实 PCM RMS。最后无新音符的行仍然有音乐，也仍有对应电平和波形。

`prepare_fullfilm_signal.py` 对以上四段各自去掉两端 80 ms 后，用每个 80 ms 窗去均值的交流信号独立复核；报告为离线数值检查，不宣称人耳试听。

## 全片气氛

既有 `OWV5Atmosphere` 的公开数据数组扩为 17 个天空/主补光键；前八键沿用 V5。后半依次为苍白、警示红、机械青灰、去饱和、近黑、深蓝、暖地平线、日出与余温。苍白与红色的地平线亮度略低于交接候选值，避免把音乐层、素材和人物同时推满。

184.32 秒开始进入近黑，在 186.88 秒达到完全撤空的星场/地面：三个星场 renderer 停显，稳定网格 renderer 停显，主补光只留极低强度。197.12 秒后缓慢恢复星场，网格从零渐回。远处保存点的灯、保存物及其叙事由后半场面模块制作；这里不以染黑天空代替近景撤去。

tracker 后半透明度按段落变化；235.52 秒低音接力时增强。186.88—197.12 秒面板完全撤去，内部真实谱面、电平与四轨采样仍继续；再兴时恢复。面板的视觉撤空不改变持续 PCM，不按旧交接的“只剩 CH3”删掉实际发声轨。

## greetz 贯穿

前半继续使用原图集、原曲线与复制的新材质，去掉 133.12 秒的“全片结束”淡出。新环在 133.12—134.40 秒交接，匿名劳动角色整条掉落，灰色“转载”“搬运”“来源：网络”留在空位附近；逐渐减速，在 184.32 秒达到零速度，并于 186.88 秒熄灭。

197.12—207.36 秒只有一枚闪烁的 `_`；207.36 秒起新旧劳动角色共同滚入，包括尝试新工具、校译、写 README、分享源文件、保种、复现修正、搭世界、回答新人问题、受助后再帮助，以及一起玩和一起改。最后一句“那就一起做下去。”在 250.88 秒到达正前，停留后于片尾淡去。这一时段有实际持续音乐，不被称为静音。

新图集继续保留 RGBA 四通道：R 覆盖、G 描边、B 劳动角色 token 编号、A 灰色中断样式；不能按普通透明图压缩或丢弃 alpha。每一阶段按像素跨度裁切，避免灰色转载词提前出现在再兴环的另一端。

## 构建与验证

先离线运行 `~/miniforge3/bin/python tools/prepare_fullfilm_signal.py`。批量同步两个 `.cs`、新 shader、两份 JSON；两张 PNG 复制至新资源根 `Textures/`。先由主代理建立新类的 UdonSharp 程序并完成编译，然后在停止状态的全片场景运行 Build、Validate，再由主代理统一保存与实看。

Build 会复制四个荧光材质、两个 tracker 材质、原署名材质和六个气氛材质；仅替换全片场景引用。只对这些新资源调用持久化，不批量保存项目内其他脏资源。旧组件 `autoSample` 全部关闭；主调度不要额外调用旧 osc/tracker/greetz/atmosphere。

Validate 检查 7681 帧与 8192 行导入、四个能量数组、新材质路径、前半逐 80 ms 轨迹一致、四次旅行各 32 个采样点完全冻结、第二高潮只选两轨、骤空整体退远与三个星场/地面 renderer 关闭、署名环停摆/光标恢复、结尾持续电平、反向 Seek 和波形/声源同位。报告写 `fullfilm-v1/reports/signal-validate.json`，不播放声音。Unity 编译、Udon 与最终视觉验证由主代理在目标编辑器完成，离线桩编译不代替它们。

## 参考片音频

新增 `tools/render_fullfilm_audio.py`，默认输出 `~/tmp/vrc-old-web-map/fullfilm-v1/review/review-audio.wav` 和 `audio-reference.json`。输入四轨完整原音频、V5 的 29 个拟音片段、`data/fullfilm-presentation.json` 的 190 个事件；新增 8—11 号发声点直接读取 `new_emitters`，旧点位沿用 V5 的物理/旅程起点模型及实际键盘坐标。

位置复刻函数在 `prepare_fullfilm_signal.py`：`source_world_position(time,ch,data=None)`、`source_spatial_blend(time,ch,data=None)`、`motion_clock(time,data=None)`，通道零起点，物理坐标不叠加 worldFrame。前半读取的是保存后的 V4 构建中心 `(0,4.25,8.2)`、环绕中心 `(0,1.65,-2.8)`、半径 4.2 m，不能误用旧类声明里的默认中心。

四轨统一 0.8 增益，空间声像按 240 Hz 的真实位置与 spatialBlend 计算，再插值到原 PCM 采样；音频不变速、不重新采样、不按 note-on 删轨。骤空另施加四轨共同的退远包络，参考融合场与远场的距离比约 .60；这保留分轨平衡，仅为固定听点的离线空间近似，不是 HRTF、VRC 衰减曲线或实机录音。

交付 WAV 为 258 秒、48 kHz、双声道 PCM16：前 256 秒完整演出，最后 .16 秒淡出，后 2 秒编码后精确为零。生成过程没有调用播放、没有把源音乐静音，工具不提供 `--silent-music`。当前数值结果：混音峰值 −5.94 dBFS，拟音峰值低于音乐 18.48 dB，190 事件，无削波；四次旅行位移为零，空间插值位置误差最大约 0.0000291 m。报告记录全部输入与输出哈希、位置模型、峰值、拟音余量和发声点；没有将这些数值表述为人耳试听。

结束时信号层关闭波形、tracker 与 greetz，天空保持最后一键的柔和晚色，主补光保留该键的 75%，让后半公共工作区继续可近看。

## 编码与本地验收页工具

`tools/encode_fullfilm_movie.py` 只在远端 `movie-progress.json` 的 `complete=true`、整数 `frame=6450`、显式空 `error` 全部满足后编码，并在上传任何文件前执行只读门禁。完整编码程序先落成任务目录中的 `.ps1` 再上传；Windows SSH 只传短入口。脚本还检查 6450 个非空且连续编号的 JPEG、首/中/末 1600×900、258 秒完整音乐 WAV 的格式/来源/哈希，随后编码为 `fullfilm-v1-review.mp4`，验证 H.264/AAC、25 fps、6450 帧、48 kHz 双声道与时长，最后校验取回文件的 SHA256。不调用播放或 Unity，不上传世界。`--dry-run` 只打印脚本。

`tools/package_fullfilm_review.py` 要求中央集成、静态、连续运行、交互、保存、重开、SDK 构建/包检查、信号及两个后半模块报告实际通过，核对场景、音频、电影与 SDK 哈希，再生成本地 `review/index.html`。24 场面按钮读取全片 JSON；按钮仅定位，不开始播放，视频默认 `muted` 且不自动播放。图库收录实际存在的 `full_*.png`、Udon 截图与少量 V5 精确同刻对照，报告链接按现有文件生成。页面和清单明确 HMD、控制器、多客户端、人耳试听尚未实测。

两工具完成了离线语法、门禁及 HTML 行为自检；实际编码和打包仅在主代理通知 6450 帧完成后执行，离线自检不被记作成片或 Unity 验收。
