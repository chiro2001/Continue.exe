# 33 前三段 V3：可以进入的 Hub 与人物工作流

本次把 VRChat 从照片台上的题材推进成真正进入的空间。2017 New Hub 与 2019 Home/Hub 有不同的建筑、地面、座位、入口和聚集方式；四位演员从工具制作、转译校对、分发归档、维护引路的工作场所出发，经过 Avatar 与 World 的选择，最后在同一个实例里互相回应。

实现文件是 `unity/AgentScripts/OWEpisodeV3HubCast.cs` 与 `unity/Assets/OldWebMap/Scripts/OWV3HubCast.cs`。目标场景为 `Assets/Scenes/OWM_Episode123_v3.unity`，生成资源归入 `Assets/OldWebMap/Episode123/Revision3/`。本文件记录来源与演出选择，远端 Unity 不另建创意文档。

## 两套有区别的三维空间

2017 的主体是一个可穿行的十字庭院：浅石台基承托深蓝网格铺地，入口有三阶步梯与两块高告示板，后方分层入口楼冠保留黄铜水平带和成对断开尖碑。左侧 Avatar Hall 有独立抬高地面、石柱、上层梁、镜面及展示台；右侧有成列椭圆 World 门户与齿轮状冠饰，后方 Event Hall 用开口环形石梁和悬挂蓝晶体形成第二种空间重点。边缘矮栏、草带、树木和八边形坐席建立人尺度及前后层次。

2019 Hub 换成木构营火厅：木质圆平台和绿色草坪由石质边缘分开，营火有不规则石圈、交叉木柴及暖光，四周是可辨认的整根原木座椅。木柱、柱脚、横梁、开放顶棚、弯树和树冠形成上部空间，后方明确区分 Cross-Platform 与 PC Worlds 门户。蓝色轨道结构放在高处，保留画面的空间方向。银河星空使用主场景的远景体系，不能将官方照片贴到一整面墙上替代环境。

2019 Home 是旁侧的独立小会客区，保留米白墙、木梁、沙发、红坐垫、同心圆地毯、低桌、大陶盆与 The Hub 门户。它与营火厅的关系是舞台上的两个历史空间切片，不主张两者原本共用同一平面图。镜旁 Avatar selector 的位置为压缩布局。

墙面、平台、环形梁、台阶边缘、门户边框、晶体和石头均在编辑器中制作；程序网格保存为 `.asset`，纹理与材质也持久保存。运行组件只采样已有对象的变换、可见性和动作，不在播放时临时造场景。

## 前段工作流与演员接口

四个人物槽位保留用户保存场景里的原始 Rig 对象，不重建用户的刚体、材质或骨骼设置。根据首批实机图，原身体过小难以辨认，因此本版在 V3 场景内按实际渲染边界将四主演和两套替代身体统一到约 **1.25 米**，重新校准落脚与名牌高度，源 Avatar 资产不改。表演围绕正常人尺度的资料架、双层分发车、低工作托板和展示点展开。每位演员有 35 个明确时间位置、朝向、动作与视线目标，至少会多次在工位、资料架、交换点之间移动。不是每个节拍都走动；到达后的检查、取件、展示、交接、归架、维修和回应让位移产生结果。

原来遮挡人物的两张 CRT 桌和圆接触垫在本版始终隐藏。前段 Type/Inspect/Adjust 动作在停靠后显出一个按该身体双手实际位置校准的低键盘托板，显示面低矮倾斜，细支架落地；走动时收起，不让人物面对空气操作，也不再用高 CRT 壳体挡住身体。第三段直接使用维修台和兼容检查点。

新控制器保存 12 个 Humanoid 动作：Idle、Type、Carry、Present、Point、Inspect、Walk、Wave、Calibrate、Talk、Adjust、Shelve。使用独立的 `V3Pose` / `V3PoseTime` 参数，避免旧 Stage 的 `Pose` 参数改写新表演。Arm Front-Back 保持 V2 已纠正的分手轴 `0`，不再使用会交叉的 `-.6` 值。双手仍须对两套实际骨架和多个相位检查；参数值本身不能替代画面验证。

`OWV3HubCast.actors` 持有独立演员引用，运行不依赖 `stage.actors`；集成已关闭旧 Stage 的人物写入，所以每帧只在 `LateUpdate` 从 `director.Elapsed()` 采样一次。所有位置、转向、选择状态、换身结果和火焰均由传入时间确定，因此跳播与重播能够重建。换身通过保存过原启用状态的 Renderer 集合切换，两个 Animator 层级始终保持激活；离线求值也检查 Animator 自身的 `activeInHierarchy` 和 `enabled`，避免在隐藏 visualRoot 后持续调用 Animator.Update。

`OWV3HubCast.Sample(float time)` 是运行采样接口；编辑器入口 `OWEpisodeV3HubCast.Sample(float time)` 在采样后将已有 Humanoid 状态显式求值，用于离线截图。以后接动捕时将对应 `externalMotion[i]` 设为真，释放该槽位的根位置、动作和视线控制；保留 `OWActorRig` 的 Humanoid 映射和可替换 `visualRoot`。携带作品另挂在手部，可替换成正式接触道具。

## 现有资产的真实复用

主代理从 Windows 已有工程的 Room01 选择性导入模型、材质和贴图。Builder 读取已导入的 `Assets/Room01/Scene/model/Room01.fbx`，并兼容名称包含 Room01/Modern/Furniture 的其他已导入模型。它按沙发、低桌、书架和灯的子节点选择 MeshRenderer，保留源 mesh/material 引用，归一化尺寸后放入 Home 或工作区。没有导入原场景、播放器、烘焙设置或第三方脚本。

每个实际匹配的源路径、节点名和网格路径写进 `hub-cast-build.json` 的 `actualImportedParts`。首批实机图中 Living_Shelf 因单按宽度缩放而变成巨大的白墙，本版改为计算所有 Mesh 边界角点经完整变换后的局部尺寸，必要时将侧向书架转 90°，并同时限制宽、高、深。书架上限为 2 米高、0.65 米深；桌、沙发、书和灯各有合适尺寸上限，报告包含实际 `fittedSize` 与 `caps`。没有匹配的物件才使用已制作的书架、沙发、低桌或分发车，并且不会把这些回退对象计为现有资产复用。Room01 是当代辅助陈设，不伪装成历史 Hub 的原始模型。

身体归一化写入报告的 `castReadability`，逐项列出 Cast prefab 基准路径/缩放、来源高度、目标高度、求值后高度、脚部底点和脚骨位置。测量口径明确为 **V3Idle 姿态下可见 Renderer.bounds 的世界空间包围盒**。本轮确认该骨架的 BakeMesh 输出与父级缩放叠加后再做 TransformPoint 会重复计入缩放，不能将那个数值称作身高；现已移除该测量方式。每次 Build 都先恢复 Cast prefab 的固定 visualScale/visualPosition，再按一次包围盒比例拟合到 1.25 米，最后把包围盒底点落在演员根平面，不累乘上轮 V3 的缩放或落脚偏移。若测量高度差超过 1.5 厘米或脚底差超过 6 毫米，构建直接报错，不只填写目标值。头像预览引用场景内已经修正曝光的材质；本模块不改源 Avatar 材质。

原生镜子使用 SDK 的 `FX/MirrorReflection` 与原组件。已核读 `Packages/com.vrchat.base/Runtime/VRCSDK/Sample Assets/Shaders/Mirror.shader`：输出为 `_MainTex` 乘左右眼 `_ReflectionTex0` / `_ReflectionTex1`，后三者默认白色且没有 tint。编辑器未初始化反射时因此出现白板。本版仅将两眼反射纹理的材质默认值设为持久化灰蓝中性纹理，`_MainTex` 保持白色；SDK 在真实反射初始化后仍按原机制覆盖双眼纹理。离线灰蓝面是合理的未初始化外观，不表示已经验证了真实镜面反射。

## 构建与验证

由主代理统一操作 Unity。纯文本作者不单独连接远端编辑器，也不手改场景、Prefab、材质、导入设置或 `.meta`。

1. 在已保留 V2 用户存档的基础上打开 V3 副本，完成纯文本批量同步和编译。
2. 执行 `OWEpisodeV3HubCast.RepairProgram()`，检查 Udon 编译，再执行 `Build()`。Builder 只标记 V3 场景有意义的修改，场景保存由主代理统一进行。
3. 主代理的离线总采样在旧 Stage/Montage 后调用 `OWV3HubCast.Sample(time)`，并对该控制器的 Humanoid 状态求值；或调用本 Builder 的 `Sample(float)`。
4. 查看 `hub-cast-build.json` 中的持久网格、门户、动作、替代身体数量及真实资产路径；镜面若报告 SDK 或 Shader 缺失，只能说明银色占位面，不能汇报已验证反射。
5. 按 81.92、84.48、85.76、89.60、92.16 秒截图，补看前段多个工作点；第三段补看 104.96、112.64、120.32、125.44、129.28 秒，确认人物确实换位置、手不交叉、身体替换、UI 选择与空间切换有前后关系，并有检查与保存结果。
6. 验证镜面、低视点、左右视点和完整时长跳播/重播；按项目惯例停止 Play Mode，等编译结束，保存有意义的场景改动。

首批实机问题修正后须重看 23.52、43.52、88.64 秒原视角：确认两侧不是巨大书架墙、四人至少有完整上半身和腿部可辨、旧 CRT 不再遮人、真实头像卡仅占上方窄带，并检查本轮新增 inactive Animator 警告数量为零。身体高度与家具尺寸报告通过后仍必须以这些画面验收，不按纯静态通过收尾。
