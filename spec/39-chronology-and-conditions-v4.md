## 年代口径

主线按画面所描绘的内容、产品版本或平台事件推进。来源发布日期、Wayback 捕获时间、文件上传时间、图像实际拍摄时间是不同字段，不能相互代替。比如 Commons 在 2014 年上传的 IE6 截屏不等于 2014 年的 IE6 界面；档案站在 2001 年发布 Windows XP Build 2474 文件，也不说明后世截屏摄于 2001 年。年代审计逐项保存这些日期语义；缺少逐图证据时不指定历史 `display_year`，只允许在 122.88—128.00 秒“回看·旧网页还能再打开吗？”窗口呈现，不拿回顾文章的发布日期补成截图年份。

## 重点错序与待核素材

- 两张 Windows XP Build 2474 素材描绘 2001 年预发布版本，V3 却放在开场，应移到 20.48—30.72 秒；字幕需说明 2001-05-17 是 Internet Archive 条目日期，截屏日未标。
- IE6/Wikipedia 图在 Commons 的原始上传日是 2014-10-21，不是拍摄日。若保留，放入 2000 年代浏览器语境并写明截屏日期未知，不能用上传日证明它是 2014 年界面。
- Winamp Classic 皮肤条目标注 2005-07-07，现有位置过早；建议放到 40.96—51.20 秒。
- 32 张 Aegisub 文档图片 URL 位于 `/img/3.2/`，可归入 2011—2014 字幕工具组；`fansub-07363843c1c1` 的 URL 位于 `/img/3.5/`，必须单列，不能因同属 Aegisub 就把它写成 3.2 或 2014 的截图。每张图的拍摄日期都未标。
- BitComet 素材存在版本冲突：`distribution-49fed831d550` 的图库标题称 0.63（该版本 2006-03-07 发布）；`bitcomet-053-main` 截图标题栏实际写 0.53（变更记录对应 2004-06-15），而图库标题写 0.63。不能把 0.53 画面改称 0.63。选项窗口未显示版本，待补证后再归年。
- eMule 0.47c 的 Commons 上传记录为 2006-10-23，宜放在 2005—2007 分发段；熊猫烧香配图来自 2007-02-04 同期新闻中的网络二创，不是病毒感染截图，应放在 2007—2010 中文社区段。
- QQ 2003 与 QQ 2005、MSN 7 应按产品版本归入对应社区阶段。2012 微博登录页应后移至 61.44—71.68 秒，不放在字幕工具段。
- Unity 项目版本选择图的文件名含 2018-12-18；SDK Build & Publish 教程发表于 2017-11-24；旧网页世界资料图文件名含 2018-06-28。三者都是后世来源/教程素材，应放在 VRChat 制作语境，不能伪装为 2000 年代屏幕。文件名日不自动视为截屏日。
- VRChat 2017 Hub 公告、2018-11-06 更新、2018-11-17 Unity 更新分别依自己的来源日期排序。2018-10-02 Trust and Safety 图应归入 VRChat 主线，不应排在 2022 EAC 之后。
- 2010 3Q 材料可以在 102.40 秒后出现，但必须以“回看·2010”作显式回闪；不要用素材复用字段代替叙事标签。

爱范儿 2020-04-29 原文的 47 张网页图已按原始 image URL 与相邻图注逐项匹配。图注明确给出单年页面的，按该内容年份归入主线；例如 MSN 与 Canon 为 2000、PixelSurgeon 为 2001、Hasselblad 为 2002、Nikon 为 2003、Facebook/Yahoo/Xbox 为 2004。图注年份说明页面内容语境，不是图像拍摄日。

原文把六组网站演变图标为跨年份内容：Apple 1998—2018、LEGO 1997—2020、Coca-Cola 1996—2020、Nintendo 1996—2018、Space X 2002—2017、2Advanced Flash 2000/2002/2003。它们在逐项审计中标为 `timeline-collage`，不拆成未说明的单年截图；建议统一放在 122.88—128.00 秒的“回看·旧网页还能再打开吗？”窗口，并显示其覆盖年份。该时间是回看编排位置，不是图中网页发生年代。

其余图注只给出“1990 年代”主题、早期版本或网站名称的，保留 `display_year: null`，也移入同一回看窗口。单独指出几处素材名冲突：`web-3f83e8fcf4ff` 是 2Advanced Flash 页面而非 Photoshop 工作区；`web-c2c1ffd0ae2d` 是水木清华 BBS 而非个人 GOTH 主页；`web-c67afdf13526` 为网易邮箱而非 Baidu 搜索；`web-f71d87cab7b5` 为图注标 1999 的网易主页而非 Baidu 分类目录；`web-c5615a468003` 是 90 年代网站组里的 Adidas 页面（画面提示需 Flash 4）；`web-cc00d289047d` 是图注标 1996 的百事可乐官网而非 Shockwave 页面。V4 展示名以审计 JSON 的 `corrected_title` 为准，原 V3 名保留作追溯。

## 102.40 秒之后的史料用法

3Q 材料分别代表同期新闻配图、腾讯官方公开信、媒体报道中的单页调查和论坛讨论。CNET 报道配图可证明当时公开争议中存在这些弹窗，不裁定双方指控真伪；腾讯公开信是公司一方立场；新浪调查是单一媒体页面里的选项，不是全网民意。YUKI 原帖现已找到公开链接（主题《老子决定再也不用QQ了！》，作者思兼，帖子显示 2010-11-04 12:19），原帖与打印页链接见条件来源 JSON。它可用于引用一位参与者当时表达的意见；本地图片仍是当前打印视图，不是 2010 年论坛界面，也没有确认编辑历史。演出只显示原帖日期和标题，不展示打印页框架、帖子自留邮箱或考据说明。

没有找到 2010 年 11 月可核验的微博热搜榜截屏：Wayback CDX 对 `s.weibo.com/top/summary` 该时段没有捕获。当前页面只反映 2026 年。不能补画榜单、排名或“热度”，也不应把一页调查改造成热搜证据。

后续平台材料要分清“事件”“页面”和“截图”：Messenger/Skype 官方公告提出全球逐步迁移，但当时暂时保留中国大陆；Google Reader 于 2013-07-01 退役且提供 Takeout 导出；Adobe 于 2017-07-25 公布 Flash 支持结束计划，支持于 2020-12-31 结束，内容从 2021-01-12 起被阻止运行。Adobe 配图是抽象公告图，不是 Flash 错误窗口。它们说明入口与运行条件可能变化，不代表某服务/技术在一个瞬间于所有地区和设备上消失。

VRChat 2022 EAC 材料中，官方安全公告、Secure Instances 信息图、社区无障碍请求、官方回应和 Mod 作者结项说明各有视角。公告内的 Locked/Unlocked Links 截图是链接示例，不是 EAC 启动错误框；文件名中的 2022-07-13 未独立核验。2022-07-26 的可访问性意见帖是具体用户请求，截屏所见票数是 2026 页面状态，不能当作总体民意统计。官方 7 月回应表达计划，不等于计划已全部交付。emmVRC/emmCVR 作者在 2022-10-17 讨论功能取舍、其他开发者接续与长期疲惫，不能归纳成“EAC 是唯一原因”。

如引用 Reddit API 抗议，The Verge 所供的两张图均显示 `r/aww` 私有页面；报道文字另提 `r/Music` 参与。它们可以呈现个别版块的抗议页面，不能把截图中的版名替换为 r/Music，也不能概括所有社区的状态。该案例发生在 2023 年，若纳入就应作为 2022 之后的补充。

Google reCAPTCHA 2026 演示页的图片验证图只代表当代挑战示例。Google Cloud 当前 quotas 文档正文说明超额时可能出现 HTTP 429/`RESOURCE_EXHAUSTED`；本地截屏只显示配额表，没有显示错误段落，因此不能把它当成 429 报错截图。VRChat 当前帮助页曾截到 Cloudflare 验证页，Adobe 当前 EOL 页面曾返回 Access Denied；两者都已列为失败尝试，不作为史料。

## 编排建议

条件变化段先用有日期的 2010 同期材料表现“必须选择”的争论，再推进到平台规则、服务迁移和 2022 VRChat 安全/无障碍材料；用户意见、官方陈述、媒体调查和创作者回顾应通过来源身份区分。如纳入 Reddit 抗议图，须保留画面中的 `r/aww` 名称，并注明事件为 2023 年；它只能作为 2022 之后的补充，不能被写成 2010 或 2022 事件。随后在 122.88—128.00 秒回看未定年旧网页与跨年份网站组图，128 秒后以“现在（2026）”回到项目的检查、修复、保存和维护动作。实体屏障表达准入门槛，选择通道要可恢复；不要通过移动碰撞体推挤站立玩家。

详细的每张素材首个非 `recall` 出现位置、完整播放区间、场景名、日期语义、证据链接和建议区间，以 JSON 审计为准。该审计供 V4 编排修正使用，不改变 V3 score，也不代替逐项的来源/权利检查。
