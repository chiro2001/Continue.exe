## 情绪曲线

```
怀念  ▁▂▃▄▅▆▇  (第一幕，光点最亮)
窒息       ▇▆▅▄▃▂▁▂▁  (第二幕，光点逐排熄灭)
希望                          ▂▃▄▅▆  (第三幕，克制的回升，不超过第一幕的亮度)
```

亮度与色温是两条独立的控制轴：第一幕偏暖（老 CRT 琥珀色），第二幕褪成冷蓝并对比度下降，第三幕出现一种前两幕都没用过的颜色（例如青绿），强调「换了介质」而不是「回到过去」。

## 卡点与实现约定

- 每段开头有唯一 ID（`cold-boot`、`act1-golden`、`act2a-netdisk`、`act2b-opensource`、`act2c-vrchat`、`act3-hope`、`outro`），Unity 与 JSON 共用。
- 段落内的事件（节点熄灭、弹窗落下、引文卡出现）由 `data/timeline.json` 的 `events` 数组描述；每个事件带 `beat`（小节序号）与 `t`（秒）双坐标，便于重编曲后重新贴合。
- 音乐重排导致时长变化时，只改 JSON 与 `beats.json`，不改场景。
